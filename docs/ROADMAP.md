# 下一阶段路线与验收条件

更新截点：2026-11-04 14:39:44，Asia/Shanghai。十批train145/dev42，数据数量、全量编码及基础模型缺陷检查均通过；受控微调6198已启动，正式前三次更新有记录。阶段1、2已完成，阶段3进行中；阶段4、5待验证。详见[最新结果](MEETING_20261104_UPDATE.md)。

## 1. 完成数据准入

继续原种子计划，完成整批资格、物理执行、审计和去重导出。保留原门槛：train≥120快照/24布局、≥40恢复/12恢复布局；dev≥40快照/8不重叠布局；两任务、至少两类有效修正。

严格保留规划拒绝、安全/完整性隔离及全部执行消耗。不得靠重复观测、共享首帧、临时降低阈值或人工追加同案例次数补数据。

## 2. 证明存在可学习缺陷

对同一最终导出执行全量多模态编码审计和完整基础模型对照。模型只读公开输入，私有已测后果由独立评估进程读取。

至少3个独立开发种子有已验证成功选项，同时基础模型输出非法、提前STOP或选择已测失败动作；未测动作记unknown。若不满足，保留结果并重新评估训练价值，不能将unknown改作失败。

## 3. 进入受控视觉微调

通过上述门槛后冻结Qwen3.5-4B、NF4/FP16、文本LoRA rank8、lr5e-5、seed42、microbatch1、累积4、1epoch。先做最长训练样例更新/独立重载，再从基础权重开始正式训练。

确认每个样例在epoch中恰好使用一次、loss/梯度有限、参数有真实变化、产物身份一致。最终adapter另起进程重载并核对参考logits。代码检查通过不能替代真实更新和重载结果。

## 4. 验证收益，而非只看loss

同公开开发输入比较基础模型和新adapter，显式启用新adapter；非法、提前STOP、已测成功/失败、未测及矛盾后果分别统计。

之后在新条件上做同权限、同预算的规则/基础模型/微调模型物理闭环，报告整体与任务/布局分层成功率、恢复率、真实尝试与观测成本。开发集用于选择，最终盲测留到版本冻结后。

## 5. 论文汇报与限制

当前任务与动作分布不均衡，尤其胶囊和偏移/减速恢复较少。模型增益、分布外泛化和真机迁移均未证实；材料随机化尚未接入当前采集。
