# 第三批多机制困难任务

目标：200条件、400规则/混合闭环任务。两组物体容器×五类干预×20新种子。用户已批准第三批约400任务和先验证后批量执行。

五类干预：抓取XY偏移、放置XY偏移、挡板碰撞、抓取偏移与挡板复合、抓取与放置偏移复合。偏移方向按种子固定，抓取幅度2.5—6.5cm、放置幅度10—18cm；相同种子在单因素与复合组共用偏移，复合只组合原值。布局轻微扰动1cm和12度，各机制共用布局。注入仅修改planner偏移和挡板，不修改成功判据，不给模型提供故障真值。

种子920001—920020；前16个训练候选（160条件/320条目），后4个开发验证（40条件/80条目）。920101—920120预留未来测试，不运行。旧heldout测试组合不使用。配对规则/模型共享候选、场景、残差噪声和最多3次尝试预算。噪声沿用6种XY残差配置，缺失不补零；错误类型、阶段和接触几何保持理想。仍然不是视觉噪声实验。

资格先行：每条件先无干预控制，控制成功再执行干预初始动作。静态几何、配对初态、实际注入调用和原始物理结果审计通过后，干预失败计challenge，成功计easy_control；两类都保留执行，单列结果。不通过控制或几何条件的两方法条目明确跳过，不替换种子。控制未通过不代表场景在所有策略下都不可解。

预算：资格控制最多400次物理执行，另计400闭环任务、最多1200次尝试。复合故障可能三次预算仍无法恢复，这属于实验结果，不放宽预算。首种子×五机制×两物体共10资格冒烟条件（最多20次执行），复用进200条件；对应20闭环冒烟条目复用进400总分母。

实现只写hard_cases_v1，新包hardstudy复用已冻结的候选、选择器、执行器和评价。fault字符串保持none以避免旧隐式注入，显式intervention元数据及实际grasp_bias/place_bias调用留在物理审计侧。每次尝试重新施加同一干预，不因重试自动消失。无隐藏模型重试、无非法输出兜底。
