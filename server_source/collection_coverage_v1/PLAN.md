# 正式数据覆盖审查

目标：在已有数量门槛之外，报告正式训练/开发数据经资格筛选和自然失败筛选后保留的任务、相机、颜色、布局范围。只读取完整审计且正式导出的批次；不读取在途轨迹，不改变样本或门槛，不给模型新增信息。

四个阶段分别为全部增强提案、资格通过、自然失败条件、已验证恢复条件。条件按 id 去重，环境按 seed 去重；共享首态和三个探索分支不得放大环境数量。训练/开发分别展示，保留两任务的去重快照和恢复数。

风险：筛选后覆盖可能偏窄，极值不能代表均匀覆盖，单个任务只有少量种子不能宣称泛化；因此同时输出固定相机区间直方图、颜色频数、物体位置范围、每任务独立种子数。只作描述统计，不把条件成功率推广到全分布，不替代最终编码审计或真实模型对照。

验证：合成数据检查共享分支去重、跨 split 泄漏、标签与条件身份不一致和固定噪声；随后在 Slurm 上核对首批真实导出与其原汇总完全一致。新增目录独立于冻结采集/训练源码，后续批次可指定导出 job 重用，不重复物理执行。
