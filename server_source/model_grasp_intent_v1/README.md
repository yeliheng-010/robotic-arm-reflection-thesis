# 模型抓取意图：第一阶段接线

本版本将“选择抓取区域、深度、接近方向”交给模型，把位姿转换和安全检查交给规划器。它是独立的 **无运动接线版本**，没有替换旧服务或执行入口。

## 当前支持

| 动作参数 | 有界范围 |
|---|---|
| region | 顶面中心、观测长轴负侧、正侧 |
| depth_mm | 顶面下 15 / 20 / 30 mm |
| tilt_deg | 相对竖直向下 0 / 15 / 30 / 45 / 60 / 90 度 |
| azimuth_deg | 接近运动方向在世界 XY 平面的方位，0..315 度，每 45 度一档 |
| symmetry_deg | 0 / 180 度，对称闭合朝向 |

长轴偏移幅度仍为 min(20mm, 观测长度20%)；相对原名义抓点的三维位移不超过50mm。闭合方向保留原5%–95%分位跨度、12mm余量、80mm最大宽度。新倾斜/侧向选项只是提案，不是已验证能力；接近轴与原闭合轴平行时拒绝，不编造退化朝向。

坐标约定：夹爪局部 x 为朝目标的接近轴，y 为闭合轴。预抓取点应位于抓点减去接近轴的方向。模型只输出意图，不输出关节角，不选择或修改安全阈值。

## 接线关系

1. `observations.py` 接受许可的含噪目标点云、非目标可见点云和名义抓点。对模型只投影数值观测，不传私有真值、碰撞对或人工原因。输出明确提示未知空间不等于空闲空间。
2. `requests.py` 给规则与模型相同的动作、观测与预算。当前直接动作输出没有预填诊断标签，也不要求模型披露内部推理。
3. `model.py::ModelPolicy` 适配现有 `Generator.prepare/generate` 和 `VisualGenerator.prepare_images` 方法。严格检查 EOS、JSON重复键、动作范围；不自动修复模型输出、重试或代选动作。
4. `geometry.py` 复用原 `top_fit.estimate` 和 `span`，将意图变成 SE(3) 候选。
5. `bridge.py::runtime_bridge` 用原 `jv_context.stage` 注入单个候选，重新核对同观测估计、名义抓点约束和位姿一致性；不绕过旧跨度过滤。返回的 `selected` 仅表示调用方规划结果，仍须完整路径与独立审计。
6. `loop.py` 处理拒绝—再次提议、额外观测、预算和停止。没有执行动作或运动回调；即使规划返回 ready，也仅记 `plan_ready_unverified`，`task_success=null`、`training_eligible=false`。

本地回调是受信任的工程接线，控制器不是沙箱，不能保证任意第三方回调没有副作用。真实接线必须继续使用原只读规划、安全上下文与前后物理状态审计。

## 预算与数据边界

- 必须由调用方显式传入预算；本地允许上限是8决策、4规划、2追加观测，并非真实实验额度。
- 提议经过合法动作校验后，几何拒绝也消费规划额度；同观测同动作的重复提议只消耗决策次数，不再调用规划器。
- 模型/规划/观测异常都不返还已消费额度。对模型只报告标准化失败状态，不输出原始异常。
- `qualified=true` 是调用方的声明，不是本模块重新证明85%可见性合格。真实入口必须先查验原资格记录与观测哈希，禁止由模型或待验证输入自行授予许可。
- 图像由可信调用方按观测revision登记，检查根目录、文件SHA256；新revision缺图时拒绝，不静默沿用旧图或退化成文本。哈希绑定本身不证明图像与点云同步，真实采集审计仍必需。
- 追加观测后必须同步重建真实规划的观测上下文和 bridge；旧点云bridge与新拟合不一致会拒绝。
- 真实 base / adapter 对照需提供各自已核验的生成器。旧基础 `Generator.generate` 内部关闭adapter，本版本没有改变这一行为，不能把它直接称为微调模型对照。

## 本地验证

从项目根目录执行（选择可用Python解释器）：

```powershell
python -m unittest discover -s model_grasp_intent_v1 -t . -v
python -m model_grasp_intent_v1.verify model_grasp_intent_v1/新的独立验证目录
```

验证目录排他创建。测试使用合成点云、生成器替身、规划阶段替身；原顶面拟合/跨度模块另外执行真实数值回归。它们不构成真实模型推理、MuJoCo安全检查或物理成功证据。
