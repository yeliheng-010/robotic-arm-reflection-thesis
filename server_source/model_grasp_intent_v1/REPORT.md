# 模型自主抓取意图闭环：本地接线验证

本轮已完成独立版本的动作契约、观测投影、位姿生成、模型输出适配、规划阶段适配和有限反馈控制器。尚未执行真实模型推理、GPU完整规划或物理任务，不能宣称成功率提高。

## 实际变化

旧接口只允许 original→observed_top，顶面策略启用后禁止偏移。新契约允许模型选择中心/长轴两侧、15/20/30mm深度、0–90度登记倾角、水平接近方向与对称闭合朝向。保留原50mm位移限制、80mm跨度上限和12mm余量。新侧抓能力只是位姿提案，尚未验证物理可行性。

模型输入增加可见非目标点云；模型可据此选择方向，但本模块没有用私有箱体真值指定避让方向。几何模块仍使用原观测顶面拟合，因此侧抓、倾斜物体与部分观测下的拟合偏差仍是限制。

真实模型可通过 ModelPolicy 适配现有生成器方法，但本轮未实例化权重或调用旧HTTP服务。原服务有冻结manifest绑定；独立新服务/入口、模型身份、图像与点云同步审计、正式实验预算尚未登记。

控制器分开计数决策、规划、追加观测；同观测重复动作不重复规划，拒绝或异常不返还已消费预算。动作不能携带私有字段、安全开关或关节角。原始碰撞对、异常文本及私有规划结果不进入下一轮模型输入。

规划器返回ready也只记plan_ready_unverified，task_success=null、training_eligible=false。无物理执行接口。桥接器通过原jv_context.stage的候选注入约定工作；本地仅验证该协议，未导入完整远端MuJoCo依赖链。

## 自审结论与限制

本轮按TDD和verification-before-completion执行，并完成本地代码自审；没有独立子代理审查。关键边界已检查：不读仿真私有属性构建模型请求，不让模型改变安全常量，不因异常重置预算，不把selected或候选端点当成物理成功。

输入qualified=true仍依赖可信采集入口，不是此模块重新做可见性审计。真实暂停观察、物理状态保持、图像/点云同步、完整安全规划和模型请求持久化需在下一阶段接线验证。PlannerBridge的安全上下文由调用方提供；本地控制器不是任意回调的副作用沙箱。

本地没有964347胶囊的原始span_inputs.npz；没有用私有端点记录反造“公开点云”，也没有把合成测试冒充该案例回放。模型与规划替身只用于接口测试。
