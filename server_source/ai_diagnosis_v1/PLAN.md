# AI自主诊断接口：本轮实施计划

日期：2026-11-02（America/Los_Angeles）。用户已接受“由AI分析失败、我们维护可靠执行与独立评估”的方向。

目标：完成现有链路审查、形成可复核的主实验协议，并用真实旧记录验证模型输入隔离和决策输出边界。此轮不调用模型、不推进仿真、不训练，不改变原共享接口、冻结源码或既有三次预算。

本轮采用brainstorming / writing-plans轻量流程，以及定向红绿测试、自审和verification-before-completion。单线程处理，避免拆分共享协议；不commit/push。

- [x] 阅读两场景入口、模型决策链路、反馈投影、候选生成、传感器、执行接线与已完成结论。
- [x] 新建AUDIT.md与PROTOCOL.md，明确证据来源、权限、对照、预算和未接通项。
- [x] 为独立输入白名单与输出校验写定向测试，验证隐藏字段不影响输入、预算耗尽不能执行、无规则兜底。
- [x] 实现只读离线接口原型；使用两条已耗尽预算的真实账本，仅生成审查样例，不发送模型请求。
- [x] 校验旧文件身份不变、样例无真值泄漏、测试结果；同步进度和路线图。

风险：现有日志多是仿真真值，删掉字段之后不等于获得真实观测；旧OBSERVE是同快照合成残差重采样；部分参数会被路径规划器覆盖。原型不得把这三项包装为已实现感知/主动观察/有效执行权限。

验证：本地Python标准库单元测试、真实账本只读样例、输入污染不变性测试及SHA256身份核对。所有真正仿真/几何运算仍必须通过Slurm，本轮不进行此类计算。

结果：18项测试通过；两条真实账本预算0、合法动作仅STOP；21份主要源码身份未变。实际观测/模型/执行接线未完成，下一实施包和验收详见PROTOCOL.md第7节，不将此接口原型称为完整AI闭环。
