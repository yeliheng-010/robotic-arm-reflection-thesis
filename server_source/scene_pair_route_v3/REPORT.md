## 实际实施

在原验收箱内半宽中扣除物体世界外接半尺寸与20 mm边缘余量，生成中心、四侧、四角共9个XY格点，组合底面高于箱沿10/40/70 mm。约束预测物体外接盒中心，并将抓取时物体中心至TCP的偏移补偿到目标TCP。

复用原姿态、8个世界竖直朝向及8个IK构型，先过滤抓取端点，再检查27个释放目标。仅对端点合格者搜索完整路径，最多256次前缀检查、512次运输检查，固定顺序选择首条通过者。每条路径检查6段，每段51个静态采样。复用高度解耦、350/450/550 mm抬升及路点能力。

运行时用第三次的新噪声观测重新搜索。目标在GraspFlow层传入并设置`z_offset=0`，避免旧120 mm释放偏移再次叠加；执行记录器、真实执行及释放保护使用同一目标。预检与运行时目标不要求逐值一致。

外部仍只有`baseline`和`varied_noisy`。全部布局/颜色/物体朝向/相机变化、3 mm深度高斯噪声和2%缺失保持不变，目标箱10 mm机器人净空、碰撞保护、实际到位/持物保护及原落箱成功判据未修改。

## 真实成功与失败证据

961104最终`inside_xy/inside_z/supported/settled`全部为true，误差反馈为空。松爪前`held=true`，实际TCP相对选中目标的XY误差为1.971 mm，Z误差19.761 mm，分别满足原20/40 mm门槛；`strict_contacts/release_checked/open_called`均为true，保护拒绝原因为null。最终物体距箱中心54.312 mm，属于合法偏心放置，成功判据仍为箱内、支撑与稳定，不能用箱中心误差替代原判据。

961103在`move_to_point / lift / carry_lift`阶段持续0.2秒失去双侧源物体接触而报`object_dropped`；`inside_xy/inside_z/supported`均为false。实际记录内的局部`attempt=1`来自单次episode执行器，跨版本账本`steps[-1].index=3`才是该案例总尝试序号。它不是额外第四次。
