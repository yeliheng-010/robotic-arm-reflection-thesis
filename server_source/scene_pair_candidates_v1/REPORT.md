## 实现边界与真实证据

**深度恢复**：只有定位像素缺失才考虑补值；半径2像素、至少8个有效支持、四象限支持、目标内部3×3、10%～90%跨度≤20 mm。961104实际用23个点，中位数1.616274 m，跨度18.293 mm。原始3 mm高斯噪声/2%缺失数组保持不变，补值与有效数组另存。只用含噪观测与现有仿真分割，未读取干净深度或物体真值坐标补值。没有增加观测次数。

**碰撞排序**：仅第三次且前一轮grasp_pose/grasp_approach碰撞时，优先通过原完整路径检查的world_down候选；保留原姿态回退。961101选择world_down_90后空抓；961108选择world_down_0后仍碰Knife。原始候选、初态、参数和各路径检查结果按ID对应一致，只有排序与选择改变。持物和动态碰撞仍未解决。

**候选补救**：只有原StableDetector将所有候选拒绝时触发。将观测点云根据相机标定转到世界竖直坐标系，保持原PCA、角度和8 mm偏移预算，转换回相机坐标后通过原过滤器。每次生成60个候选，过滤后分别留下：961103为4/4/3个，961112为6/3/3个；六次均实际执行后掉落。

源码核对发现原排序的35°“俯视角”是相对相机光轴，而两个视角的世界竖直方向离光轴41.11°/46.24°。仅补救分支把角度评价改为世界竖直基准，保留35°上限；图像投影、目标掩码、宽度、深度一致性和碰撞阈值不变。角度评分使用代理姿态，最终交给执行器的是原真实相机坐标姿态，单测与重建审计均核对了这一点。

全部场景的布局、物体朝向、箱体配色、相机、噪声与三次预算保持冻结值；没有换种子、降低噪声或放宽碰撞过滤。原有仿真分割/定位/反馈辅助仍存在，不能宣称纯视觉或实机能力。
