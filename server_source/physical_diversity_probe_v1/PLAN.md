# 物理多样性只读盘点

当前正式协议只改变布局、容器外观、相机与传感噪声，没有改变物体密度、夹爪接触材料。自然失败目前仅覆盖方块，但首批尚未完成，不能提前断言胶囊没有可恢复失败。

先只读编译原场景，记录两目标及夹爪的质量、接触摩擦、优先级、solmix、condim、显式接触pair及执行器范围，不做动力学推进或新执行。用于判断未来若三批任务覆盖仍不足，能否另立物理材料随机化协议。不能简单降低物体friction并假设有效：MuJoCo默认接触混合可能由另一侧较大的系数主导。

本步骤没有新增训练样本、没有改变现行场景/协议、不计物理成功。未来任何物理随机化需独立版本、新种子、预登记范围、编译与静态稳定性检查、有限能力pilot和独立审计；只有两组baseline/varied_noisy，不能按失败标签临时改变参数。
