# 下一阶段准备：分别检验反馈噪声与场景变化

本轮24项闭环已完成并通过审计，可以进入带噪声的配对闭环。noise_feedback_v1已经完成6配置×4真实反馈×3投影种子的72项离线预检，完整带噪声物理任务尚未执行。当前不将开发条件转成最终测试集，也不启动训练。

## 可以进入下一阶段的门槛

1. 24个预登记任务均保留有效结果/失败状态，无静默替换；总物理预算不超过72次。
2. 新规则在两个锚点上通过已验证的动作序列；额外种子的失败应解释并留档，不因模型输给规则就删掉条件。
3. 同候选生成、同预算、状态/配置映射、初态、完整物理验收、模型原始请求/响应的审计全部通过；无未解决的接口/格式错误。
4. 所有成功修正标注规则或混合来源；模板解释不作为模型思维链。当前数据仍是开发对照，训练批准不自动改变。

## 优先实验

将残差噪声强度与字段缺失概率分开控制，建议sigma=0/0.005/0.015m、missing_probability=0/0.25形成6组。先固定物理初态，仅改变可见反馈；同一错误记录在两种策略间按相同随机种子扰动，保留未扰动的物理评价。测量缺失不能补零，规则限幅/过滤必须标注为系统机制。

保留两个不同诊断家族：本轮机械臂运输→下降碰撞，以及此前条件47的残差修正问题。碰撞阶段/身份如果仍为理想标签，必须明确报告；仅给XY残差加噪，不能声称验证了视觉噪声或阶段误识别鲁棒性。

先做6组反馈配置的离线投影和候选合法性检查，再做小规模配对闭环；确认输入、预算与来源审计通过后才冻结更大批次。新阶段规则与模型必须共享候选和尝试预算。对条件47若需要超过3次尝试，另设所有方法共同的预算对照，不单独给模型加机会。

## 场景多样化单独验证

增加未调参的物体位置/朝向种子、障碍相对位置、目标箱位置和对象形状；每个新场景先做无故障控制及可解性检查，保留全部筛选分母。新下降路径目前只在紫色胶囊任务验证，不能直接声称适用于绿柱、球体或需要保持朝向的任务。

深度噪声/丢失/遮挡属于感知侧实验，应保留清洁/扰动深度对及实际候选变化；与纯文本反馈噪声分组，不混为同一种噪声来源。

## 训练前处理

只有来源清楚、配置实际执行、相邻尝试完整恢复的数据才作为候选监督；按场景家族与种子划分，最终测试在调参前独立留出。先报告规则候选及执行器扩展的收益，再评估模型选择是否带来额外收益；若二者表现相同，如实报告，不以增加微调轮数代替有效对照。
