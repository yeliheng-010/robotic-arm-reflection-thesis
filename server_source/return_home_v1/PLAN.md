# 安全归位修复与任务成功率验证

目标：修复随机场景下已放置后归位被自碰撞保护拒绝的问题。用户已授权推进安全归位及新布局验证。相机规则作为输入门槛，保持baseline/varied_noisy两场景；不改旧冻结源码、不降低保护、不改变成功定义。

方案：原关节直达路径优先；若原51点保护拒绝，则在起点与home各关节值组成的有限中间姿态中确定性搜索两段路径。按腕关节到基座的固定组合次序枚举，最多原直达+62个中间姿态，不读种子或任务成败择路。每段沿用原关节/自碰撞/环境/目标箱10mm净空检查；全部失败即拒绝，禁止兜底执行。

时间：直达沿用原时长。备用每段均沿用原归位时长，各关节只在其中一段完成原行程，避免提高相应关节的计划峰值速度；累计为原时长2倍（原1秒则2秒）。任务尝试仍每条件1次，抓取/搬运速度不变；不能声称总运动时长完全相同。

验证顺序：
- [ ] 纯协议回归先失败再通过：端点不变、候选预算/唯一性、持续时间界限、直达优先、全部拒绝不执行。
- [ ] 仅重建6401的5个归位前状态做规划回放；原4安全条件应保留直达，964009须找到同保护下合格路径才进入物理。
- [ ] 固定5布局仅运行改变了路径的条件；其余已证明完全等价的直达条件可复用记录，逐项注明，不重复耗时实验。
- [ ] 独立核验候选选择、实际命令、原物理审计与真实接触，再以完整5条件分母报告。
- [ ] 冻结后登记新布局，保留全部资格拒绝，覆盖方块和胶囊，验证前后策略同预算结果。此为下一阶段，不能用5个旧train布局替代。
