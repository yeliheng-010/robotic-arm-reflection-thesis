## 验收与推进顺序

1. 完整任务成功率为主指标，另记首轮成功、最多3次尝试内恢复成功、规划拒绝、自然物理失败、不可用观测、模型非法动作与超预算；资格拒绝保留完整分母。各项定义不能混用。
2. 先验证执行能力：5个固定清晰相机布局已完成原策略，成功2/5，剩余2个抬升接触丢失、1个返程路径保护拒绝。测试已有observed_top作为首轮策略，5个布局全部测试，不按历史失败选子集；每布局仍最多1次新执行。此阶段最多5次新执行/0语言模型调用/0训练，不等于AI收益。
3. 原策略记录只读复用。相机、摆放、配色、任务、噪声种子、尝试编号及动作参数逐项相同，唯一处理变化是strategy=observed_top。顶面策略只读当前含噪点云，仍保留30mm深度、50mm平移上限及全部原路径/接触/关节保护。原场景资格可复用，实际顶面规划仍由执行器严格检查，不伪称已预先通过顶面可行性。
4. 依据完整结果选择后续瓶颈：若顶面能力不足，先解决抓取/搬运/返程；若能力充分，再检查AI能否从合格观测选择有效动作。补看/换视角只服务于恢复决策，不独立扩展相机研究。
5. 改动冻结后，在未用于调参的新布局和两种任务上做同预算评估，比较规则、基础模型与已训练adapter；没有独立物理评估不宣称泛化/微调收益。新训练前先确保样例与新规则一致，不把旧6198完成当成本轮训练完成。
