# 本轮自审记录

范围：`candidates.py`、`runtime.py`、`experiment.py`、诊断与验证脚本。

方式：串行源码自审、契约测试、保存点云红绿回归、真实物理对照。当前工具不提供用户指定的子代理模型，因此未派发子代理；本记录不是独立审查。

已核对：
- 新生成器仅依赖目标点云，不接收故障标签、物体名、种子或仿真真值；物理规则策略沿用旧实现。
- 原候选逐元素保留；新增方向绕原接近轴旋转，保持抓取中心、深度、高度；重算投影宽度，超宽省略。
- 原完整场景碰撞、空抓、NMS、目标约束与排序均实际执行。原阈值0.01/0.003不变。
- 生成/推理/渲染包装均通过上下文退出恢复；异常恢复有契约测试。各仿真进程隔离，不进行同进程并行包装。
- train_v1在进入物理仿真之前暴露包装位置错误：原引擎在函数内部导入依赖。已改为包装真实定义模块，保留失败日志、旧runtime源码与原manifest，使用train_v2重新冻结。
- 新种子对照在训练结束后冻结；冻结候选策略、执行包和原核心代码哈希，配置包含数值线程。
- 首次状态应比较输入状态；两组使用不同候选时不强求结束坐标一致。候选未变的任务才额外核对首次物理末状态1e-8。
- 规则反思数据明确标注rule，不导出纯模型训练数据，不调用教师服务。

限制：碰撞检测是可见点云与简化夹爪几何的近似；过滤通过不等于无真实碰撞。仍沿用原执行安全监测。世界竖直方向与相机轴不同，本轮不同时修改。体素网格原点漂移已独立诊断，但未改动原检测器。仅单个新种子、同族任务的小样本结果，不能声称稳健泛化。
