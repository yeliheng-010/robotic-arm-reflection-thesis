# 闭合安全预检与双时点评价

目标：在独立新版本识别978505旧方案的闭合风险，并使新记录能分别精确复核缓存评价与重建评价。用户已同意实施建议；原qualified_execution_v1源码、数据、claim和失败结果冻结。

实现采用brainstorming、writing-plans、executing-plans的轻量流程，关键拒绝行为用TDD，完成前做verification-before-completion。共享状态和接触规则集中，串行整合；不创建分支、不提交推送。

## 设计与边界

- 在独立MjData中固定命令机械臂，使用模型中的夹爪关节范围与connect约束求解平行指垫的名义闭合构型，从张开至最大闭合采样。只执行运动学forward，不执行step；原环境接触规则与机械臂自碰撞规则不变。
- 相比仅检查闭合端点，过程采样能捕获中途碰撞；相比重新动态试抓，本轮不消耗物理预算。连杆柔顺、自适应接触、跟踪误差和采样间隙不由名义运动学覆盖，不能把采样通过当作动态安全证明。
- 保存求解约束残差，非有限、越界、未收敛一律拒绝。保存末态仅用于独立历史回归，不参与名义构型生成或模型抓姿选择。
- 新评价工具先保存原缓存的评价所需数组与接触，再从相同积分状态在副本forward生成规范评价；两份各自精确回放，跨时点差异单列，不要求跨时点相等、不修改旧审计。
- 新运行适配器在close_gripper前拒绝不合格闭合预检，评价挂钩在原最终观察前记录双时点。只验证接线，不提供可直接绕过原预算的物理执行入口。
- 标准公开反馈只含rejected与gripper_closure阶段；具体接触、约束、真值和评价数组仅供私有诊断。
