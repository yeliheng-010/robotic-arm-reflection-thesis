# 观测动作未被选择：冻结诊断协议

来源active_observation_model_v2已经完成24条件96轨迹，基础模型82次合法决策均未选OBSERVE。可见接口中OBSERVE在legal_action_ids，未在candidates有完整条目；这是待检验的表示因素，不预先认定模型能力或数据量不足。独立目录保存新诊断，原代码/权重/输入/轨迹只读；CPU重新审计原24条件96轨迹并哈希冻结其JSON证据。不读取最终测试，不启动训练。

提示诊断覆盖全部82条原模型请求，保留原history分组和预算。四个固定变体：baseline原消息原样；unified_first仅在candidates首位插入OBSERVE条目；unified_last仅在末位插入同条目；missing_directive在unified_first上额外明确“目标字段缺测且有预算先补看”。统一菜单不改system、物理候选内容/相对次序、合法ID集合或历史，只增加补看的动作类型、说明及费用条目。首/末位用于检验位置敏感性。明确指令是专家策略注入，其结果只解释为指令遵循，不能当自主反思或微调收益。

另对41条base_current请求做结构化费用读取探针：observe_legal、observation_cost、physical_cost、remaining_observations。系统明确提供费用定义，正确答案仅由可见字段确定；这是读取显式定义的测试，不能证明模型具有物理理解。原始/统一/明确指令提示均不从结果提取标签。温度0、seed42、max_tokens128、enable_thinking=false；基础Qwen3.5-4B adapter关闭，最多16384输入token，超长拒绝不截断。两条固定旧开发输入启动回放单计；82条原消息要求文本精确复现，漂移为工程失败，不混入提示效果。

物理来源仅按base_current决策中quality任意字段missing且remaining_observations>0选择，全量得到11快照（10个条件、5个种子组），覆盖所有此类决策而非仅3个adaptive独胜案例。其中5个在第1次失败、6个在第2次失败；均余2次观测。冻结前逐项验证，不按后续成功或可恢复性筛选。当前数据属于开发诊断，不是新独立样本。

每快照固定补看0/1/2次，沿用原ap_sensor同一namespace/seed/pair/factor/attempt/observation/field随机流与原失败原始快照；各分支共享默认观测和新增观测前缀。噪声为合成重采样，非真实相机动作。聚合与候选生成保持同一中位数和原规则，只使用当前快照实际可见测量。每观测水平比较两个固定选择器：原无历史规则、同基础4B无历史执行选择。模型执行选择统一说明观测阶段已结束，仅允许物理候选，但保留真实剩余预算；不把禁止继续补看伪装成预算耗尽。该阶段不是原自主观测策略，不能直接把它的0次观测组与旧自主模型等同。

物理执行器不是恢复MuJoCo失败瞬间。准确流程是固定源失败快照与参数起点，依据每分支观测选择下一配置，再用同一场景种子重置并重试一次；一分支至多1次物理执行。报告下一次重试成功，不冒充完整3次执行闭环成功率。相同所选配置的新执行互相核验；与旧真实下一步配置相同者核验原物理结果复现。原成功判据、场景、干预和动作实现不变。

模型任务总上限402=82×4选择变体+41费用探针+11×3固定观测执行选择；启动回放2次另计。物理总上限66=11×3观测水平×2选择器。观测成本按各假想分支0/1/2逻辑计费，同一合成采样前缀可复算，不宣称66次真实相机采集。非法模型输出保留为无动作失败，仍入分母，绝不规则兜底；请求/身份/来源/物理错误停止后继，无隐式重试。

CPU协调器先运行单GPU模型诊断与CPU完整请求审计（4项篡改拒绝）；通过后模型作业释放，再四GPU执行前4快照共24分支冒烟。物理审计及12项篡改拒绝通过后，复核冒烟并补余7快照42分支，最后完整CPU审计。门禁只检查工程正确性，不以OBSERVE率或成功率高低放行。所有结果保留，不依据结果改提示、换快照或增加采样。

输出按原history组、缺测与非缺测、位置变体报告有效/非法、OBSERVE选择率、费用探针正确率和全部请求成本；按固定选择器/观测次数报告全11快照下一步成功、实际执行、逻辑观测费用、所有配对方向和分种子/失败次数。报告全部无收益与反向结果。两个选择器的信息收益分别判断，不混入选择器改变的效应。小规模相关开发快照不做统计显著或泛化主张。
