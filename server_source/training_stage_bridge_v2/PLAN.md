# 自动衔接修订版

替代已取消的6001监控。原监控启动后仍只有collecting，未提交训练链，因自审发现训练入口同名模块遮蔽而主动停止。原源文件/日志完整保留。

本版本仍使用原数量门槛与原审计/基础模型对照，唯一执行链修订为freeze_v2.sbatch和train_v2.sbatch；新微调入口恢复runtime加载时的临时搜索路径，并显式引用smoke_v2。prepare除策略测试外还验证提交链指向v2、训练依赖冻结、冻结同时依赖数据审计与基础对照。

原基准和增强两场景、原数据门槛不变。未达门槛不提交模型生成或参数更新；任务覆盖不足记录development_required，由代理继续处理。监控最多23小时，失败不自动重试已消费执行。
