# 多模态动作微调准备

当前仅开发并验证数据编码，不启动参数更新。旧 candidate_sft_v2 是文本候选动作训练，不能直接用它丢弃本轮 RGB 输入；新编码必须保留 before/latest 两幅图、公开请求及仅 action 的回答，并只在 assistant 后缀计算损失。

训练开启前必须同时具备：recovery_collection_v1 原数量/种子/恢复/动作多样性门槛、已验证正式导出、冻结基础模型对照及受控训练协议。既有 pilot 只用作只读编码接口检查，不能混入正式 train/dev。

拟沿用已验证 Qwen3.5-4B 的 NF4、V100 FP16/FP32 delta 保护、文本层 LoRA rank8 与稀疏后缀损失；图像编码与推理保持相同 processor 配置（128²..448²），不截断输入。正式训练预算及模型身份将在门槛通过后冻结。
