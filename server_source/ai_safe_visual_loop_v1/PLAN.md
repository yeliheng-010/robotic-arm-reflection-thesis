# 安全执行器上的真实视觉三方法闭环

目标：固定规则、AI直接决策、AI诊断决策共享首次执行与默认观测，各分支最多3次执行、跨尝试2次补看、4次模型决策。仅baseline/varied_noisy，原变化与3mm/2%噪声保持。

前置：新登记种子的可见性/有限几何资格；更深偏移工程批次完整独立审计与至少一次实际自然恢复；视觉HTTP服务完整审计通过。条件未满足不得启动物理/模型闭环。

执行器从首次启用world_down、完整路径、自碰撞、硬件限位、0.15m抬升、1.5倍时长，保留动态接触、释放检查和10mm箱净空。公开动作STOP/OBSERVE/RETRY/SET_GRASP_OFFSET/SET_TIME_SCALE；新版本偏移单轴单步最多30mm、累计每轴最多50mm（比旧全局250mm更窄）。旧10mm接口及冻结文件不改。三方法权限完全相同。

固定规则在未知深度时先补看；否则先下移30mm，再以3倍时间执行。规则不读错误标签/根因。AI自主选择合法动作与假设，实际执行后才能计恢复。OBSERVE仍是同相机同暂停状态新渲染/新噪声，不能声称会换视角或获得新时间点。

输入包含真实before/latest RGB、公开执行事实、带来源的模拟深度/编码器摘要；解释lift_height是抓取后的相对抬升距离，避免当成绝对抓取高度。禁止根因、真值残差、未来结果等字段。独立审计重建每个输入、动作状态、完整物理轨迹和真实模型编码。

本版先用于工程验证，不自动计正式训练。通过后再冻结按种子隔离的训练/开发采集协议。当前只是开发，尚未运行。
