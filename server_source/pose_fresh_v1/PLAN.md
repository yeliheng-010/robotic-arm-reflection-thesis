# 独立布局验证：原版优先与选择性孤立点修复

预登记新种子978101–978112，共12布局。与训练保留范围964001–965024分离；登记时扫描已有manifest/protocol，遇重叠即失败，不偷偷换种子。分区为新观察验证队列，不用于训练；因结论可能影响后续设计，不称最终任务留出集。

正式场景仍仅baseline/varied_noisy，本轮只验证varied_noisy。7实例随机/7背景固定，布局范围、容器颜色、相机范围、3 mm噪声/2%缺失保持。只验证胶囊跨布局/绕竖轴姿态；不把胶囊模型应用到方块，不宣称独立持物姿态或其他形状已验证。

每布局先做原场景编译/边界检查，初始化按现有实现静置500步；随后禁止所有积分入口。最多256相机候选找首个通过原全部14实例可见性/尺寸/连通性/入画/深度标定的初态，失败布局完整保留，不进入抓取或私有估计诊断。

合格布局在同一暂停状态检查5个固定槽位：原合格方向、方位±20°、仰角±12°。仍限制原范围；无效/出画/标定失败均保留，不补替代方向。每标定通过方向3组固定新噪声，最多180单视角点云。额外方向不满足整帧门槛时只作私有诊断，不输入模型/训练或控制。

每布局按固定槽位序枚举夹角≥10°的最多3对，完整保留3组噪声，最多108双视角融合。三策略共用同一观测：原版、始终筛选、原版优先+拒绝后修复。选择只读质量布尔值；拟合和选择落盘后才用真值评价。原6 mm残差/1e4条件数/10 mm跨视角中心/12°长轴门槛不变；筛选参数6近邻、4倍中位距离、最多5%剔除、至少128点不调参。

验收重点：全队列资格覆盖；每布局/视角的接受、误接受、修复分支新增误接受、原已接受结果丢失；以布局为实验单位。至少8个合格布局才视作本轮覆盖足够，但不将其解释为任务成功率。新误接受>0或资格不足时不接入在线控制。原版自身误接受也阻止宣称整体可靠。

资源预算：先独立登记/测试CPU作业，再12个场景子任务、最多2并发，每项1GPU/8GB/8分钟；最后独立CPU审计。每场景单独进程释放渲染资源，禁止重提已消费子任务。全部任务物理抓放/模型/训练为0；标准初始化静置不伪装成零仿真步。
