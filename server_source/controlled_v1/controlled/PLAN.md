## 固定协议

每任务最多 3 次执行；Flash 温度 0、seed 42、max_tokens 1024、关闭 thinking。
每个物体—目标组合固定一个场景种子，在故障和因素组间匹配。扩展计划为四组合、两个种子、共 192 条件；本次不自动扩大。
layout：物体 XY ±30 mm、yaw ±60°、容器 XY ±15 mm、槽位打乱。
sensor：深度高斯 sigma=3 mm（截断 3sigma）、缺失率 2%。
physics：密度 ±30%、滑动摩擦 ±25%。
feedback：残差 sigma=5 mm（截断 3sigma）、可选测量缺失率 15%；错误类别、执行阶段和候选数保持理想测量。
mixed：复用各单因素组完全相同的随机实现，不重新抽取扰动。

## 风险与验收

这是开发集实验，非封存测试、非真实机器人传感器验证。物理真值评分与模型反馈隔离不等于已经使用真实视觉估计器。
预检不以任务成功率筛选场景，也不保证 IK/路径可行；未触发故障的场景保留并计入首次成功，不算恢复。
验证包括：因素独立与混合一致、训练组限制、反馈输入无坐标旁路、历史不重新扰动、非法动作拒绝、服务错误分类、配对初态和参数执行审计。
当前外部阻塞：8080 无响应，管理员管理的 local-llm-engine.service 超时退出；不修改该服务或中断他人任务。
