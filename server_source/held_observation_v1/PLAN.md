# 持物观察与估计的有限验证

目标：验证964347胶囊抬升后和释放前的合格RGB-D观察、相对TCP位置/主轴估计；不硬编码旧65mm真值偏差，不调用模型、不训练、不执行补偿或释放。

旧6486没有两个阶段的完整状态，不能用终态冒充。先做本地暂停接线测试、远端合成几何测试和真实入口零任务运动预检，再独立登记最多1次只采集的物理运行。保持旧候选、路径、速度、所有原安全门槛；不修改旧目录或重提交已消费任务。

暂停观察不得推进仿真或改变控制量/积分状态。每阶段最多32相机候选，在原相机范围内寻找至多2个方向间隔至少10度的全14物体合格视角；保持85%可见性等原条件和标定检查。失败只留私有快照，不放宽条件。

拟合只读取含噪深度、分割掩码、标定和编码器TCP，采用胶囊形状先验；输出中心和无符号长轴，长轴滚转不可辨识。多视角拟合残差和一致性为质量门槛，不称校准概率。沿用模拟辅助分割，不能冒充真实语义识别能力；私有物体真值只用于误差评价。

物理运行只在原搬运执行器的env.step返回后触发观察，禁止拆分/改写命令。抬升后观察、搬运完成后观察，然后用显式异常停止，禁止open_gripper。始终release_authorized=false，task_success=null、training_eligible=false。观察失败可继续原已检查运输以采集第二阶段，但仍不得释放或使用不合格图像决策。

独立进程恢复每个完整状态，禁止mj_step，复算相机、拟合和输入哈希；对照6486直到释放前的接触/状态/命令序列，核验采集没有改写物理轨迹。预检每进程180秒，采集最多360秒、独立审计240秒。原4次模型预算不恢复，无Git提交/推送。

采用TDD、自审和verification-before-completion；结果区分接口通过、图像合格、估计质量、任务成功和训练资格。
