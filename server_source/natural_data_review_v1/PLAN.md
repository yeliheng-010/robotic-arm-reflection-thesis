# 自然闭环数据盘点

只读取已通过独立审计的轨迹，不执行仿真或模型调用。首批ai_natural_loop_v1是开发试验，明确不进入正式训练/开发划分。

同一任务、相同暂停物理状态与干净深度视为一个失败快照；同状态补看、不同策略共享首帧不能虚增独立数。按模型可见输入另存请求身份以便复核。状态/干净深度仅用于私有去重与审计，不能进入训练输入。

仅将实际执行且下一次结果成功的修正记录为直接恢复候选。其它失败动作、STOP、无效输出、观测链保留，不将其自动伪造为正确监督。成功轨迹里的较早动作可作轨迹分析，但不能直接标为单步恢复。模型assessment不作正确根因标签。

盘点不自动触发训练；总计划的数据量、种子隔离、动作覆盖和可学习缺陷门槛继续有效。
