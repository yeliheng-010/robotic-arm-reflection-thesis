# 主动观测与相关执行历史：运行前固定协议

研究问题：同样的传感信息、有限补看和物理执行权限下，基础4B是否比固定补看/强规则自适应更好；增加同轨迹过去修正动作及结果是否改变表现。不是检验新微调效果。前轮规则资格试验仅净增1/24成功、节省4次观测，不能据此假定本轮模型会获胜。

固定新种子940301—940306（6组），RedBlock→BlueBin和PurpleCapsule→RedBin两物体对、grasp_bias和grasp_place两故障家族，共24条件。冻结时只读既有protocol/manifest检查种子无重合。全部train_candidate开发用途；6组而非24独立种子。保留控制失败、几何不合格、初始成功、策略失败及零收益，不因表现改种子。

独立目录active_observation_model_v1；物理/成功判据、场景与动作候选沿用冻结实现。传感器沿用ap_sensor：同失败快照合成重采样，sigma=.005m、3σ截断，缺测.35，离群.25且各轴±.06m，namespace942800，随机流含seed/pair/factor/执行索引/观测索引/字段。它不是相机主动移动；错误类型和阶段仍是理想执行器标签。缺测和离群作为共同压力，不独立归因。

每轨迹至多3次物理执行，至多2次额外观测，默认一次观测免费；成功即停。四方法共享合格初态，之后独立实际执行。相同状态/索引时匹配噪声随机流，动作分歧后不强求相同物理状态。最多每条件2次资格执行+四组各2次后续=10次唯一物理执行，总上限240；最多96轨迹。

fixed_first在第1次执行失败时用完额外观测预算，以当前窗口中位数和原阶段规则选动作；adaptive在目标字段缺失、有效数少于2或两两距离超过30mm时补看，否则保留预算；两者仅看当前状态且无历史规则。当前窗口中位数、质量启发式、当前参数/阶段、候选生成器与动作权限在四组相同；模型可选择OBSERVE或任何展示的候选ID。OBSERVE每次扣1观测费，采样后重新决策；执行候选扣1物理尝试。无剩余观测时从合法动作中去掉OBSERVE。没有合法动作或非法输出时结束该轨迹为失败，不用规则代选、不修补/重试模型输出。

base_current与base_history使用同一基础Qwen3.5-4B、同一system提示、温度0、seed42、128新token、enable_thinking=false、adapter显式关闭；每次生成最多16384输入token，超长停止而非截断。两者同样看到本状态实际采集窗口、中位数、质量摘要、当前执行状态、剩余观测和执行预算、完整候选；唯一差别是history。history仅本轨迹已经执行的修正前状态、所选完整动作及后续成功/错误类型/阶段，最多1条用于第二次失败决策。不含旧残差、原始物理真值、噪声标签、未来信息或其他方法结果。历史不参与候选生成，不自动屏蔽旧动作；模型自行利用历史。空history不声称没有过去执行。

同一失败状态可多次模型决策，但观测总预算跨状态共享；每模型轨迹最多2次补看决策+2次修正决策=4次调用，任务上限192调用。启动额外回放旧开发输入0、52两次，验证基础身份与输出另计。底层基础权重/依赖、提示和执行代码hash冻结。HTTP服务1张Slurm GPU，3个仿真分片各1张GPU。模型请求串行处理，不受并发生成随机性影响。

主结果为固定3次执行预算内成功率、初始失败恢复率，报告全配对方向、分家族/分种子、实际物理尝试/额外观测/模型调用/token和推理耗时。累计第1/2/3次成功属于该三次预算策略的实际过程；因为模型看见剩余执行预算，不能声称这些前缀等价于重新设置1/2次预算的独立实验。不计算小样本显著性或泛化结论。机制计数与成功率分开：后续补看、缺测恢复、非法输出均完整保留。

预检包含预算/隐私/历史/非法响应测试，冻结后从/tmp验证路径。首种子4条件16轨迹冒烟，CPU重新构建实际请求、原传感窗口、实际物理结果和预算；28项真实篡改拒绝及账本通过才自动批量完成剩余条件。工程门禁不要求任一方法获胜。传输、模型身份、审计或物理执行错误停止后继并保留现场；不无痕重跑，冻结后修复须新版本。最终CPU审计通过才标完成。关闭本机不影响服务器协调。

不自动启动训练、不读取最终测试、不改历史冻结实验。若存在可学习缺陷，再设计有来源标注、真实物理验证、多解与失败记录的训练集。若模型与规则持平或更差，如实报告。
