# 正式数据的基础模型对照

只接收已经完整审计的 recovery_dataset_v1 导出。按布局隔离的 dev 自然失败输入全部去重纳入；STOP 来自该导出的 dev 正样本上限。训练输入不用于此项对照，也不读取最终盲测。

inputs.jsonl 仅含公开请求、原始两图路径与哈希、系统/用户消息、匿名输入ID；private_outcomes.jsonl 单独保存已执行动作的真实后果。模型函数只接收 inputs，不接收私有后果。基础模型与既有固定规则使用同一个公开请求与动作权限。

冻结后每条最多一次生成，2048 token、temperature=0、seed42，与既有视觉服务相同；生成开始先保存标记，异常不得无痕重试。参数更新0，不做新的物理尝试。原始响应、EOS结束状态、合法性均保存。

评价分列：非法输出、已验证成功动作、已验证失败动作、同输入同动作混合后果、未测动作、失败现场提前STOP。未测不能标为错误；离线命中不等于物理成功率。多个成功动作都接受，不用唯一标签准确率替代。统计以输入和自然快照两种分母报告；因分支历史/预算不同，同快照可对应多个输入。

这里只提供可学习缺陷证据；训练开始仍需原数量门槛、数据审核、冻结训练协议和重载smoke。最终效果要用新种子、同权限与同预算的真实闭环比较。
