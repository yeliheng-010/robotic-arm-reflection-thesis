## 多有效动作标签

162条隔离记录对应77组完全相同的可见输入，全部为 `collision / place_descent`。这些输入对应两个不同但各自有紧邻物理成功证据的动作，例如 `descent_minus45` 与 `descent_minus90`。没有歧义组跨训练/开发集合。

它们是“多个观察到的成功动作”，不能简单称错标签。当前保守单标签版本暂不纳入；全部原始记录和候选信息仍在provenance及analysis_details中。不能因未命中唯一参考action_id就把另一个实际成功动作判为失败。观察到相同可见反馈，也不等于所有隐藏物理状态完全相同；尚未做同一物理状态下全部候选的反事实验证。

因此49条开发标签集仅用于无歧义格式/选择诊断，不能替代完整开发场景闭环评估。歧义、失败、首次成功以及资格跳过均保留在原实验分母中。

## 下一步

建议用159条保守数据先做候选选择器的1轮微调流程验证，同时制定针对训练种子的复合故障补采；不把增加epoch当解决方法。训练前核验实际基础权重身份、可训练格式、上下文长度与显存；不得只按服务别名选择模型，不把旧参数修正adapter直接当作新选择器。

训练、开发验证及旧场景诊断分别保留。正式闭环对照固定同一初态、候选、噪声、最多3次尝试；比较规则、未微调模型和微调模型，在完整开发条件上报告成功率、尝试数、无效输出和延迟。预留测试继续封存。
