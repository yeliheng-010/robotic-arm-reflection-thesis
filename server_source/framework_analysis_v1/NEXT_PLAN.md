状态更新：首轮12条件资格已在mechanism_pilot_v1完成，55次独立物理执行，12项测试与15项篡改拒绝通过；具体实现边界和发现见该目录PLAN.md/RESULTS.md。以下保留本阶段原设计；主动模型决策、跨状态估计、正式训练采集与微调尚未运行。保留原框架基准，不改既有数据或通过增加难度保证某方法获胜。

## 先完成12条件资格试验

两个既有物体/容器组合×三个任务机制×两个全新训练种子，共12条件。种子需在实现冻结时与所有既有训练/开发协议查重；不读取保留测试。此数量仅用于验证机制能运行和监督能核验，不作为论文最终样本量。

### 机制A：任务相关的间歇缺测与重新观测

模拟抓取或放置定位短暂遮挡；只在当前故障真正需要XY残差时计入有效缺测场景。重新观测不执行修正、不改变物理状态，使用当前可测状态重新生成独立噪声与缺测掩码，不回传内部真值，不保证成功。

每任务最多3次物理执行和2次额外观测；分开记录执行与观测成本。所有反馈方法拥有相同观测权限。先做固定观测策略控制，以区分传感器提供了更多信息与模型主动决策贡献；再比较有/无历史。同样保留无额外观测对照。

资格：同一个无状态变化的观测必须可重放且有来源；更新观测不能改变执行次数；历史中有/无相关测量分别标注。当前两个共同失败场景仅作开发诊断，不能导入训练。

### 机制B：测量不一致时利用历史估计

模拟传感器偶发离群测量或持续偏置，明确噪声过程与测量坐标系。不得通过删除本应可获得的当前执行状态人为制造优势。历史估计必须处理期间已执行的参数变化及测量过期，不能直接照抄旧残差。

资格：记录同一潜在故障下连续带噪观测；确认历史估计存在可核验的用途，而不是仅增加提示长度。增加历史中位数/鲁棒估计规则基线，避免将简单滤波收益归因于语言模型反思。真实历史与移除历史的干预配对，必要时做仅离线的打乱历史诊断，不把虚构历史当成功监督。

### 机制C：复合故障中的修正副作用

针对下降姿态与放置偏移修正的耦合：前一步能通过某阶段，但后一步可能再次引入碰撞。保留合法、可执行且无正确答案标签的动作菜单；所有组同状态下菜单一致，不由历史自动过滤失败选项。

资格：机械执行路径应能产生“修正改善一阶段、损害另一阶段”的记录。记录各阶段实际通过/失败、动作与最终验收；先用预登记有限分支确认有至少一条预算内可行路径，并保留无解条件。额外资格搜索成本独立记录，不能计作模型性能。

## 比较方法与单变量原则

保留当前单步/完整模型，均用基础4B。增加使用同样历史信息的确定性规则/状态机基线，再与只读当前反馈的规则比较；当前固定重试结果保留作原基准。不要同时改变候选信息、观测预算、执行预算和模型权重。

候选说明消融独立进行：在相同候选数值动作下比较原规则说明和中性动作说明；不能仅删explanation而保留measured_*等同义提示后宣称去除了提示。必须保留执行动作语义，不能让模型盲选未知动作。数值动作来自可见测量仍是外部计算贡献，应明确说明。

## 从资格试验到训练

资格可追溯、物理审计通过、信息边界正确后，才扩展新训练种子。保留成功/失败、多成功动作集合、延迟成功、额外搜索成本与来源；不能把未试动作标为失败。训练集按照机制覆盖与独立种子统计，不按重复日志条数凑规模。

新输入接口稳定后，先完成基础模型闭环与新数据去重审计，再做同输入/同预算的单答案与多成功答案微调；必要时保留机制适配前模型作迁移对照。不得用旧189输入直接宣称训练了主动观测或历史估计能力。

## 停止与推进条件

- 工程/信息边界失败：停止后续，保留现场并修复。
- 方法成功率低：完整记录，不删除条件、不按模型喜好换种子。
- 历史仍无增益：报告负结果，继续评估反馈获取与修正机制的贡献，不预设必须微调有效。
- 完成开发冻结后，再设计独立测试的场景、种子组和样本量；当前12条件不承担统计泛化结论。
