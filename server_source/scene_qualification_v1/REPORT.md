## 可支持的结论与下一步

这12个条件能在本次有限位置/朝向扰动下稳定制造可归因的运输挡板碰撞，可进入后续开发恢复评估。它们尚未经过模型恢复实验，不能称为12条模型修正成功样本，训练批准数为0。

范围仍仅有两类物体/目标组合、三种子、小幅单因素扰动；位置和朝向没有混合，其他噪声未开启。12/12不代表更大噪声范围或未见物体的成功率，也不宜当成12个完全独立场景家族做显著性推断。

下一轮先冻结恢复评估方案，以相同初态和尝试预算比较纯模型、混合候选选择、规则优先和无修正重试。完成后再按位置、朝向、传感器、物理参数、反馈分别增加强度，最后组合；保留各级控制失败的完整分母。本轮没有启动192次扩量或新微调。
