# 实现自审与验证

当前会话串行自审，没有声称独立子代理review。按轻量planning、定向测试、systematic-debugging和verification-before-completion执行。

- 原批次、训练代码和权重均不修改，新的结果由外层uid区分rule/base/tuned；内层item严格与父协议匹配。
- 仅调用原批次episode和audit，实际偏移注入、反馈噪声与物理判据仍由原冻结实现执行/复核；不能用标签匹配替代物理检查。
- 本轮manifest冻结180唯一任务、60开发条件、源码与父协议/资格记录/adapter身份；verify逐条核对方法映射和开发split。
- 模型服务同一权重和量化实例，单线程避免两个adapter模式并发修改；base禁用adapter，tuned启用同一个已完成adapter。服务启动前独立重载及离线回放必过。
- 请求完全按原messages函数重建；服务端与任务端双日志必须完全一致。原始结果哈希、事件身份、候选ID及物理状态都参与审计。
- 8项边界单元测试通过。实际冒烟审计通过前还需在base/tuned真实记录副本分别篡改物理哈希、请求模型、可见反馈、响应身份，8次均必须被拒绝后才写gate。
- 已修复v1结束标记误判：只改服务协议判定，不改生成本身。原5110失败保留，未派发物理任务。v2服务5111回放与训练期结果一致，独立重载误差0。
- worker有输出但无summary即拒绝重跑；服务失败没有隐藏重试/规则回退。已完成smoke任务在batch阶段重新审计后复用。
- 最终审计会释放本轮自建模型服务；不触碰他人作业、root服务或绕过Slurm。
- 当前已启动冒烟和后继依赖链，尚不能称完整180任务通过或模型有效。
