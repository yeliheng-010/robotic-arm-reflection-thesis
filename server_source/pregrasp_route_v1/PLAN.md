# 抓取前关节路径绕障验证

clearance_pose_v1在固定964345方块真实初态中找到48个安全抓取端点及648个安全放置端点，但96条前缀路径均在pregrasp关节直达段与RedBin碰撞，尚未进入搬运。另两个胶囊条件仍无安全抓取或放置端点，不扩大其路径搜索。

只为这一由预登记条件确定的路径阻塞案例复用return_home_v1已验证的关节分段算法。每次先原直达，再至多62个由起终点关节分量构成的中间姿态；原51点/每段、限位/跳变、自碰撞、环境/目标箱净空检查不变。各段原时长，备用前段合计最多从1.5秒增至3秒；起终点和抓取/搬运参数保持。

静态规划与独立审计先行，仍用真实初态快照，绝不执行失败候选。仅全路径通过后登记该条件1次物理首轮，继续原实时保护与独立物理审计。不重跑已完成成功条件，不修改旧冻结源码，不把候选端点通过当任务成功。

这是当前抓取策略的有限路径能力扩展，非AI决策改进；0语言模型调用/训练。只影响独立实验入口，原baseline/varied_noisy两场景和全分母保持。
