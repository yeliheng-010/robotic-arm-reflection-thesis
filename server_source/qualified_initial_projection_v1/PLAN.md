# 新合成初态的零积分可行性方案

用户采纳制定新合成初态并先零积分验证的建议。本轮允许构造独立候选副本，不授权初始化、闭合或其他积分；不覆盖旧快照/源码/失败/claim。

候选来源为6859保存的after积分状态：机械臂已位于冻结closure.command，速度/热启动/外力已按原方案清零。本轮不重复这些操作，仅在副本中调整被动手指角。

## 固定规则（求解前登记）

- 两个driver角原样保留，原driver等式容差1e-7rad保持；不强制两侧spring相等。
- 可变变量仅right/left的coupler、spring_link、follower共6角；其他积分状态逐元素不变，包括机械臂、自由夹爪基座、场景物体、控制与时间。
- 原8关节限位保持，每个可变角同时限制在原角±0.01rad（约0.573°）内；这是候选改动上限，不是安全容差。
- 每侧独立做一次SLSQP局部约束投影：最小化3角改变量平方和，固定driver，连接约束取夹爪base坐标中的平面两分量；最终复核完整3维残差≤1e-7m。
- 角度目标尺度1e-3rad、连接约束尺度1e-3m，ftol=1e-14、maxiter=200。只有原范围与改动上限交集内的裁剪初值，无多起点、重启或碰撞驱动的调参。局部结果不声称全局最小或唯一。
- 任一侧求解失败、非有限、越界、超过改动上限或最终完整约束不合格，整候选拒绝；不扩大上限、不降低容差、不开始动力学。
