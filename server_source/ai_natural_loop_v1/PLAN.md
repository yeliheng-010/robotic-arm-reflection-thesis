# 自然失败闭环首批

执行来源：../AUTONOMOUS_TRAINING_PLAN.md。2026-11-03 America/Los_Angeles。首批是开发数据，不是训练就绪或最终盲测。

拟种子962301、962302；每种子两场景、两任务，共8条件。prepare扫描旧清单确认未用后冻结，不按结果换种子。原sd_layout/factors采样，几何预检；不依搬运成功筛选相机。相机不可见、候选不足也保留自然失败，不通过改小布局或噪声来消除。

初始参数沿用原initial()：time_scale=1、抓取偏移0、原姿态配置。每条件首次执行共享给fixed_rule、direct、diagnostic。成功则三方法结束；失败后在仍保留的同一环境上各自观测，噪声流按scene/attempt/observation配对且不含方法ID。分支在独立目录记录共享第0帧的引用；初态env在全部方法结束后关闭，各分支后续新尝试的env单独关闭，避免嵌套全局close补丁。

各方法最多3次执行（含共享首尝试）、跨全部尝试共2次额外观测。每次执行后默认1帧。每AI最多4次调用，不规则补答；STOP、非法输出、服务错误、成功或预算耗尽均结束分支。两个AI的system提示只有诊断输出要求不同，公共状态/历史/权限格式一致。共享证据和分歧点哈希留档。

动作：STOP/OBSERVE/RETRY/SET_TIME_SCALE/SET_GRASP_OFFSET。不开放候选索引、放置目标、姿态、夹持力。参数范围用已有严格解析器，实际调用前再次验证，运动包装器核对请求/实际参数，路径51点与10 mm目标箱净空、接触和释放保护保持。每次新执行重置到登记场景；历史位置不得当作重置后当前位置。

固定规则只读同一白名单：当前源或目标深度不足且有预算时补看；否则按预登记的保守时间倍率序列1→1.5→2进行新尝试。若无可用调整则RETRY，预算终止则STOP。它是通用固定基线，不称为最优或强规则，不读取错误类型或根因。

首种子4条件先运行并审计；工程门禁通过后同冻结协议运行第二种子。全批上限56次物理尝试、64次AI请求、48次额外观测；每条件至多7次环境执行。模型服务无生成回放，每请求唯一ID，无网络/生成重试。两进程在本作业GPU内运行，服务仅监听localhost，任务结束或异常仅清理本作业进程。

审计：父身份、种子隔离、完整条件记账、逐轨迹预算、共享首帧、无未来信息、非法输出拒绝、请求参数到执行、每次状态/噪声、松爪保护和资源关闭；所有自然失败/拒绝/错误保留。成功轨迹不自动等于最优动作或正确根因。训练准备门槛按总计划，此批不能直接启动训练。
