# 上线前自审

本轮为主代理自审，不标称独立评审。仅新建framework_ablation_v1，未修改任何既有冻结源文件或权重。使用writing-plans、executing-plans、verification-before-completion流程；预检失败定位采用systematic-debugging，按requesting-code-review检查边界。

- 方法来源：两模型方法仅请求base；推理服务保留已有adapter加载/回放核验，正式调用必须active_adapter_sha256=null。
- 历史隔离：共享rows_for显式传入空历史；单步prompt的history恒为空；完整prompt仅携带过去可见错误、before、selected。测试证明已选候选不会被共同候选生成器隐式排除。
- 固定重试：保持参数/配置，完全不调用候选生成和模型；每次原物理重置，允许读取成功终止信号。
- 公平预算：主3次/补充4次分开；相同资格、初态、物理判据与噪声投影；4次前缀必须复核。
- 进程隔离：每任务单独进程；复用审计有锁；临时补丁退出恢复；无worker对共享物理模块并行改写。
- 无人值守：Slurm协调器检查每阶段退出码与审计门禁，失败不提交下阶段；只清理本轮子作业与自己创建的服务进程。原始失败不自动覆盖重跑。
- 统计边界：共享6种子组的60开发条件，不作最终盲测/显著性结论；规则模板不叫模型思维链；没有新训练。
- 首次CPU预检5174为28通过/1失败，失败是继承test_adapters仍断言旧四组名称。冻结未执行，修正为本轮四组；保留原日志，重新预检。

最终验收仍须查看预检日志、真实冒烟物理审计、20项记录篡改检测、主实验及最终报告。源码自审不代替运行验证。
