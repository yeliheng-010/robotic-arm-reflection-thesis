## 第一轮优化

1. 网络输入从随机 5000 点改为固定种子的 20000 点目标感知采样，其中默认 65% 来自目标、35% 来自场景上下文。
2. 碰撞检测改用完整场景点云，可以检测桌面和相邻物体；同时过滤夹爪内部为空的姿态。
3. 修复 `gg.nms()` 返回值被丢弃、NMS 实际未生效的问题。
4. 候选排序由“模型分数 10% + 表面均值距离 90%”改为模型质量、目标中心、掩码边缘距离、俯视角和深度一致性的联合排序。
5. 候选必须满足目标掩码、Robotiq 2F-85 宽度、深度误差和接近角约束。
6. SAM 模型和 GraspNet 模型按进程缓存；SAM 不再被固定 30 px 圆截断，并加入提示点深度带与小掩码拒绝机制。
7. 相机内外参从 MuJoCo 运行时读取，不再在多个文件复制场景常量。
8. 放置轨迹以目标表面和释放间隙计算最终高度，不再固定加高 0.4 m 后下降 0.25 m。
9. 增加任务级成功判据：读取 MuJoCo 物体真实位姿，报告抓取位移、放置 XY 误差和成功状态。
10. 增加无需神经网络的 PCA 短轴俯视抓取后端，适合当前简单桌面任务。

## 后端选择

- `hybrid`（默认）：使用增强 GraspNet；无可靠候选时自动回退几何抓取。
- `geometric`：完全绕过 GraspNet，使用目标点云的短轴、宽度和中心生成俯视姿态。
- `graspnet`：只使用增强 GraspNet，适合对照实验。

## 新模型升级判断

已审计 Scale-Balanced Grasp。它基于 GraspNet baseline，发布于 CoRL 2022，官方环境为 Python 3.7、PyTorch 1.6，且需要单独获取权重。直接放进当前 Python 3.10、Torch 2.10、RTX 5070 环境会引入较高的 ABI 和 CUDA 风险，因此第一轮没有强行接入。

下一轮应先建立随机物体位姿的批量基准，再以同一套后处理接口比较更新后端。只有候选成功率、碰撞率和最终任务成功率均超过当前 hybrid，才切换默认模型。建议目标是每类至少 20 次随机试验、总成功率不低于 90%。
