# 微调后同输入离线对照

目标：在正式训练和最终 adapter 独立重载通过后，复用冻结基础模型对照的全部公开 dev 输入，每条生成一次，比较实际已测选项。仍只有 baseline/varied_noisy 两种场景；本目录不生成新环境、不做仿真、不使用最终盲测。

边界：新增独立目录，不修改冻结模型、采集、训练或基础模型评测源。生成进程只读取公开 inputs；私有动作后果只由后处理报告读取，不传给模型。生成参数与基础对照相同：seed42、贪心、2048上限、两图处理与结束原因规则一致，区别仅为启用本次训练 adapter。已有基础生成不重跑。

顺序：策略/入口测试及源码冻结；等待正式训练成功和最终重载报告；冻结输入/模型身份；生成；独立核验与配对报告。保留每次生成开始记录和原始响应，失败不自动补跑已消费输入。

报告分别展示自然失败输入和已完成 STOP 输入；未知动作、重复测量结果矛盾均单列。已测失败/非法/提前STOP转为已测成功可称离线改善，反向变化称离线退化，涉及未知的变化不作成败推断。保留 seed 分组和同输入配对表，不把多帧当独立布局。该评测不能证明物理闭环性能提升。
