# 世界竖直抓取与静态路径检查 v1

## 假设、改动和来源

旧诊断明确5例有原动作可恢复、6例无本轮原候选成功。原相机系俯视方向在世界系有倾角，
运输保持该方向；原预抓取静态检查只覆盖机械臂终点，没有覆盖移动中的夹爪自由刚体。
新动作不改抓取坐标，只在第三次尝试、已有反馈为抓取碰撞或运输IK时启用。
原规则仍负责候选和参数选择；新增确定性几何专家姿态适配，不使用LLM、不微调。

候选顺序：原姿态，世界系X轴竖直向下，闭合Y轴取原Y轴的水平投影，依次偏航
0、180、90、-90、45、-45、135、-135度。坐标和参数不变。
各候选复用旧预抓取分支选择，再按实际规划器抽样检查6段路径，每段51点：
预抓取、接近、到达抓取、抬升、运输、下降。同步机械臂关节和夹爪自由刚体至法兰。
固定选择第一个通过所有抽样的候选；若无候选通过，显式记录并回退原规则姿态。
原姿态被保留在首位，以免无依据地改变已可行运动。

使用完整仿真几何、关节和物体状态，必须标注simulation_geometry_expert。
沿用原监控定义排除源物体、目标容器和支撑面接触。静态检查保留夹爪初始张开状态，
不预测携物动态、不预测控制跟踪误差、不检查释放后回程。最终成功必须由真实仿真判定。
路径检查必须保持原环境状态及机器人状态不变，不能偷跑物理尝试。

## 开发验证和晋级

对container_decision_diagnostic_v1的全部11个固定第二次失败快照，
使用原规则的第三次动作状态，各执行原规则与几何适配1次，共22次物理执行。
保留所有失败；原规则11例须重现旧结果。独立重建几何检查、选择索引和实际执行状态。
只有新增恢复至少1例且不损失原成功案例，才进入新种子阶段。否则停止晋级并保留负结果。

## 新种子验证

预先固定950501–950540共40个新种子，CPU预检核对未出现在既有登记清单。
两个任务：RedBlock→BlueBin、PurpleCapsule→RedBin；三容器全部随机移动，
沿用container_layout_v2的采样分布、碰撞体几何和8mm静态间距，无额外噪声或注入故障。
共80个随机布局条件、两方法160条方法轨迹；不是80个独立布局。
前两次尝试按原规则共享执行与决策，只有前两次均失败才分别执行第三次。
每方法最多3次尝试，原始状态重置；不从失败瞬间继续。共享次数单独报告，不伪增物理样本。
先4条件四卡冒烟及审计，再76条件四卡批量及最终审计。
禁止根据旧案例或新验证结果修改冻结代码和候选顺序。需要修改则新建版本并说明样本用途。

## 工程验证

TDD先验证缺失行为：5448测试7项、5项预期断言失败，无导入错误。
冻结前完成语法、结构与行为测试；身份包含旧源文件、本轮源码、协议和预登记布局。
