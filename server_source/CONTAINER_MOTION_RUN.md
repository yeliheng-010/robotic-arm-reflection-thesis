## 目标与实现

上一轮11个失败中，5例有原动作可恢复，6例原候选穷举全部失败。改进优先关注执行能力。
原几何“俯视”使用相机坐标，换到世界坐标仍倾斜；运输沿用该姿态。
原静态预抓取检查只看机械臂终点，夹爪自由刚体不随虚拟关节移动。

本轮在第三次尝试遇到抓取碰撞或运输IK反馈时，添加世界X轴竖直向下的8个偏航姿态。
原姿态保留首位，抓取坐标、参数和物理预算不变。每个候选复用原预抓取分支选择，
再抽样检查预抓取、接近、抓取、抬升、运输和下降的完整规划路径，每段51点。
检查中同步机械臂与夹爪自由刚体；保持实际场景和机器人状态不变。
固定选择第一个可行候选，没有候选通过则明确回退原规则。

检查使用完整仿真几何，是几何专家模块，不能声称为纯视觉/纯模型推理能力。
不预测携物动态、闭合夹爪形态、控制误差或释放后回程；最终结果仍由完整物理执行判定。
