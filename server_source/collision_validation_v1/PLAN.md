# 碰撞候选在新布局上的前瞻校准

用户已授权执行上一轮方案 C。固定两组物体/容器配对，每组使用新开发种子 904241、904242、904243；每个种子禁用/启用候选挡板配对，共 12 个计划运行。不查看最终测试集，不依据模型恢复效果挑选种子。

保持 layout 噪声，关闭物理、深度与反馈扰动；候选几何沿用已校准值。完整编译场景先检查与障碍的保守边界间距，再核验运行时 500 步稳定后的全 qpos。初始不合格、控制失败、未触发、提前阶段失败均保留，不补采替换以美化触发率。

本阶段只验证碰撞注入，不评估模型恢复，不产生训练样本。假设新布局可能改变运动路径，固定障碍未必能在所有种子触发；这本身是要测量的结果。

验收：12 个计划条目均有状态；可执行配对初态一致；控制完成；启用障碍在抓取后 lift/transport 阶段由 SafetyDivider 实际接触触发 collision。其余结果分别报告，不合并为成功注入。

执行结果：12/12完成，6/6初态配对核验通过，3/6无挡板控制成功，2/6达到预定transport碰撞；另1组为descent碰撞，3组控制失败。全部记录保留，未启动模型恢复实验。见 REPORT.md 与 verification.json。
