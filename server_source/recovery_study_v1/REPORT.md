# 反馈可靠性与碰撞恢复对照

本轮35/35次开发实验已完成并通过独立复核：15次条件47反馈诊断、20次新碰撞恢复。条件47仅在理想反馈下由规则/混合方法恢复；碰撞部分规则、混合与guided均成功2/4，没有观察到模型的额外成功收益。新发现的阶段误读和接触部位表达过粗，需要先修正再训练。

## 设计与主要判据

条件47保持原混合物理场景和最多3次尝试，仅切换noisy、ideal、missing_xy三种反思器可见反馈；每种分别比较重试、原规则优先、原混合选择、候选1→Z−0.01m、Z−0.01m→候选1，共15次。

碰撞恢复从前轮12组合格条件中预先选最小种子905001，覆盖两个物体组合和位置/朝向扰动，共4条件。每条件比较重试、阶段规则、随机、混合、guided自由生成，最多3次尝试，共20次。阶段规则在运输/抬升碰撞时优先选择合法抬升候选，其余回到原规则优先逻辑。候选生成器与混合/随机相同。

完整任务物理成功为主要指标。抓取恢复后发生放置错误仍计失败；轨迹阶段仅作机制解释。冒烟2项属于35次分母，主批次审计复用，不重复计数。所有失败、非法输出和服务错误保留。

理想反馈下规则与混合的动作相同：第1轮运输掉落后，将grasp_offset改为[0.006564684,0.000798359,0]m；第2轮完成抓取运输但物体落在容器外，随后将place_offset改为[−0.154913836,−0.007744572,0]m；第3轮完整任务成功。

原带噪声反馈下，两者也选择相同动作，但首次抓取补偿变为[0.000899912,−0.003910884,0]m，最终未恢复。三种反馈的第一轮物理轨迹与原参考相同。重试和两种固定序列各自在三种反馈下的参数、传感器记录、物理结局及最终位置一致，3组阴性对照全部通过，支持反馈干预只改变决策输入。

这些结果支持一个条件内的结论：在固定物理场景下，反馈配置能改变规则/混合闭环的恢复结局。noisy同时包含残差扰动与随机字段缺失，不能进一步归结为某一种噪声的普遍效应；单个固定条件也不能给出总体成功率。

两种固定动作顺序都在第3轮进入放置评价并出现object_outside_container，属于阶段进展，但仍是完整任务失败。不能把这种进展改计为成功样本。残差缺失时，规则选择候选1后改深度，走到放置阶段；混合选择先减速再改深度，仍在descent掉落。最终结局相同但动作并不相同。

规则与混合在理想/带噪声两组动作相同，当前仍未发现模型选择的额外成功收益。固定序列已用完两次修正预算，尚无机会处理随后暴露的放置错误；更长共同预算能否恢复，需要另行验证，不能据此推定有效。

## 新定位的问题：阶段语义与接触部位

1. 执行器的`move_to_point`由lift→transport→descent三段组成，最后一段前往释放位姿。`descent`在此是搬运后的放置下降，不是抓取前approach/grasp。源码依据为`training/refine/instrumentation.py:7`以及`grasp_process.py:532`（尤其587处的T6释放轨迹）。
2. 紫色胶囊位置条件guided第2轮将其解释为“descent phase (approach/grasp)”，据此换抓取候选；这段解释与执行器语义不符。模型还称此前抬升无效，实际记录表明运输碰撞已被绕过、错误发生在之后的下降阶段。动作合法不代表解释正确，本轮0非法输出仅指解析/执行约束。
3. `reflection/sim_sensing.py`通过`body_rootid`把机器人接触归并为根节点名称。因此`ur5e_base`不能当成底座本体，`2f85_base`也不能直接当成夹爪基座本体。对应累计几何接触记录实际出现right_follower与wrist_1_link；累计记录没有逐尝试标签，不进一步将每个接触强行分配到某一轮。
4. `contact_bounds_world`依据根body直接几何体取包围盒，不能代表实际接触连杆/几何体的包围盒。该字段没有传入当前模型投影，但会误导人工诊断。后续应保留实际geom/body和根节点各自身份，而不是混用。
5. 现有混合候选生成器对collision主要提供抓取候选/抓取偏移，并只在lift/transport提供抬升；没有针对放置下降的独立候选分支。这是需要验证的动作覆盖缺口，不能直接将失败归因于模型参数量或训练轮数。

源文件哈希、关键代码摘录及原始反思例子保存在[analysis/source_evidence.json](analysis/source_evidence.json)。这些是本轮只读诊断发现，尚未修改冻结执行器或原始反馈；旧数据不能事后改标签继续声称同一协议。

## 结论边界

只有一个固定条件用于反馈诊断，一个开发种子的4条件用于碰撞恢复，不能作大范围泛化或显著性结论。错误类别和阶段标签理想化，模型只读取文本投影；反馈数值来自仿真，不是实体机械臂测量。guided自由生成与混合的动作空间、提示和输出预算不同。

规则、诊断序列和混合模板说明均有独立来源标记；模板不是模型思维链。详见[实验计划](PLAN.md)与[实现复核](REVIEW.md)。全部结果仍为开发证据，训练批准数0，本轮不扩到192次、不新增微调。
