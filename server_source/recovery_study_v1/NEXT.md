# 下一轮建议：先修正反馈语义，再验证动作覆盖

本文件是基于35次已完成实验的后续建议，尚未执行。原协议及数据继续冻结；新实验应使用独立目录和版本。

## 1. 修正反思器可见的语义

在独立适配层明确action+motion_segment的含义：move_to_point/descent表示放置下降，move_to_grasp_pose的approach/grasp才是抓取接近/闭合。提示及候选策略使用一致映射，不只靠含糊的descent单词。

碰撞遥测保留实际geom、实际body/连杆及root类别，区分“用于归类的根节点”和“真正发生接触的部件”；包围盒必须对应实际接触几何，并记录attempt及运动阶段。旧contacts字段的兼容性与新增字段可见范围应在新版本明确冻结，不能改写旧数据。

验收：构造真实放置下降/抓取接近两类反馈，检查模型与规则是否选择相应阶段的参数；用一条真实碰撞轨迹核对geom/body名称及位置。文字因果解释另行审核，不把JSON合法当作解释正确。

## 2. 先证明放置下降存在可用修正

对紫色胶囊两个失败条件做固定参数诊断，保持控制、物理初态与预算一致。预登记少量合法释放位置/姿态或路径方案，先验证既有动作能否恢复。若必须增加路径自由度，应单独作为执行器能力扩展评估，不能混称提示提升。

只有找到实际可行且阶段相关的动作后，再把这些动作纳入新候选生成器，与原规则、阶段规则及模型做同候选对照。若无可行候选，记录覆盖不足，不训练模型猜一个不存在的解。

## 3. 反馈可靠性与多阶段预算

条件47以理想反馈恢复、带噪声失败为固定诊断锚点。分别改变残差噪声和缺失率，避免继续把两者绑定；比较原补偿、保守补偿/复测策略与模型选择。任何过滤或限幅均标注为系统机制，不冒充模型自主推理。

两种固定抓取序列都用完两次修正后才暴露放置故障。可另做所有方法共同的3次与更长预算对照，不能只给模型额外机会。主指标始终是完整任务成功，阶段进展单列。

## 4. 扩量与训练门槛

在新增反馈与动作覆盖验证通过后，才运行其余合格种子及更大噪声范围；新增场景仍须控制先行、保留全部筛选分母。继续区分纯模型、混合和规则来源，按场景家族/种子划分数据，最终测试不用于调参。

本轮已生成的错误阶段解释不能直接进入训练。成功修正须经过来源、反馈、执行参数及物理转移审核；模板说明不作为模型思维链。当前不建议通过增加微调轮数处理观测语义或执行动作空间的问题。
