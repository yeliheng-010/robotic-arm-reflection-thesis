# 扩量实现检查

本次采用本地人工式代码复核，未派发子代理。复核范围为新噪声适配、运行队列、原始物理与可见反馈审计、依赖门槛。

- 物理执行器及评价沿用冻结版本。每个worker是独立进程；进程内临时替换attempt/physical的上下文退出时恢复，不跨任务线程共享仿真引擎。
- 配对方法共享噪声种子；随机实现和attempt进入种子；幅度配置不进入种子，保持公共随机数。零噪声重复仅作重复性对照。
- 模型只收到扰动后反馈、候选、参数和可见决策历史。原始值留在noise_audit；真实记录测试证明擅自增加请求内容会被审计拒绝。
- 冻结144项；先运行12项，再复用到全分母。原始目录和日志使用排他创建；无法悄悄覆盖既有结果。
- 冒烟物理失败不阻止扩量；非法输出、服务异常和审计错误阻止扩量。批量阶段保留非法输出，服务异常停止该分片后续启动，另一分片独立运行。
- 汇总按pair_id比较方法，避免把不同噪声配置混为同一配对。相同状态下复核噪声审计、反馈和候选；物理结果另与旧锚点对照。
