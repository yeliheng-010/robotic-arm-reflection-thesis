# 多样化场景与噪声实现计划

目标：在独立实验模块内扩展 UR5e 场景变化与传感器噪声，保留现有实验和封存测试。

架构：profile/config 产生固定 manifest；model_editor 在编译前改动 MuJoCo 场景；render 包装只改变输入深度图；复用已验证的 StableEngine 和 FlashReflector。所有原始状态、噪声统计、种子、实际参数、模型调用单独留档。

技术：Python、NumPy、MuJoCo MjSpec、Slurm、现有 OpenAI 兼容 Flash-Next 接口。

设计选择：仅修改提示不能改变真实任务难度；无限随机化容易产生无解场景。因此采用有界域随机化，先检查几何可行性与真实渲染，再运行配对闭环。第一版不改变机器人结构、成功判据或既有核心代码。

## 分级方案

| 参数 | clean | light | medium | strong |
|---|---:|---:|---:|---:|
| 四个基本物体 XY 抖动上限 | 0 | 15 mm | 30 mm | 45 mm |
| 物体位置槽重排 | 否 | 否 | 是 | 是 |
| 物体额外 yaw 上限 | 0 | 15° | 60° | 120° |
| 容器 XY 抖动上限 | 0 | 8 mm | 15 mm | 25 mm |
| 密度相对变化上限 | 0 | 15% | 30% | 45% |
| 滑动摩擦相对变化上限 | 0 | 10% | 25% | 40% |
| 深度高斯噪声标准差 | 0 | 1 mm | 3 mm | 5 mm |
| 深度缺失概率 | 0 | 0.5% | 2% | 5% |

故障偏移不再是固定答案：calibration 随机平面方向 25–65 mm，placement 随机平面方向 100–180 mm，collision 隔板半高 140–210 mm。故障参数在同一 scene seed 的所有噪声档及各方法之间一致，不暴露给模型；无故障任务占实验矩阵四分之一。

clean 是无新增域随机化/传感器噪声对照，故障强度仍按新协议采样，不与历史固定偏移结果直接合并。

风险边界：几何约束检查不保证 IK/抓取可达；碰撞与无候选等合法失败全部进入分母。深度噪声改变实际抓取点云；文本反馈仍包含标明来源的仿真真值残差，尚不是完整现实传感器估计系统。第一版不添加图像噪声，因为现有反思端点仅使用文本，避免无效视觉增强。
