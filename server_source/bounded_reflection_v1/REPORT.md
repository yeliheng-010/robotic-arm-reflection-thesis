# 有界反思方法的开发验证

本轮实现独立的混合方法，并完成96次合成检查、30次闭环对照及独立核验。混合方法成功10/12，规则优先成功5/6，均为83.3%；混合的12条动作序列全部与对应规则基线相同。本轮未观察到模型选择的额外增益。

## 为什么采用独立混合方法

此前自由生成提示在边界用例中出现过±0.25m范围外的动作，以及说明与实际动作不一致。本轮先实测服务端约束：作业4755完成6项探针，数值和整数边界4/4符合、枚举1/2符合；其中一次返回不在允许集合的unknown。因此不能把JSON Schema请求等同于硬约束解码。

新方法在执行前由本地程序构造并验证候选。实测偏移按当前绝对值减残差生成，保留Z；边界限幅、实际变化和是否饱和写入候选事实。缺少测量时只生成明确标为探索的动作。非法、无变化、历史已尝试的同一修正被过滤。候选顺序由内容确定性打散。

这里的“测量”是仿真反馈经投影与指定噪声处理后展示的数值，不是实体机械臂实测；不得据此声称已经实现真实视觉误差估计。

模型返回格式为`{"action_id":"候选编号"}`，本地严格拒绝未知编号、额外字段及重复JSON键，无隐式重试或代选。解释来自动作模板，来源为`deterministic_action_template`；它验证文字与动作对应，不证明因果解释正确，也不代表模型自行计算或学会控制规律。原纯模型方法与结果保留不变。

## 后续决策

不立即扩到192次或新增微调。本轮成功记录保留为混合/规则开发证据，不直接批准为训练样本。模板说明不作为模型思维链训练目标。

下一轮优先解决两个可检验问题：一是对条件47单独做反馈干净/带噪声/缺失及候选切换、Z探索的有限配对诊断，保持其他配置与尝试预算一致；二是在已通过资格筛选的新碰撞条件中评估恢复方法，保留纯模型、规则、随机及混合对照。诊断与恢复评估应分别冻结，不按成功结果补种子。

只有证明候选覆盖有效、存在需要反馈可靠性与历史判断的选择问题，并在新的开发条件验证后，才扩大数据采集。训练前须按来源去重、隔离场景家族和种子、审计实际成功转移，最终测试持续封存。
