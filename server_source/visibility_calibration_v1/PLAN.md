# 可见比例经验标定，替代未经验证的85%假设

用户明确说明85%是随意设定，授权先寻找高成功率临界点。旧85%不再作为研究中不可挑战的假设；历史正式记录及源码不改写。当前阶段仅在独立恢复环境诊断，不把低比例实验图像直接投入真实控制。

目标：分别测量画面通过率、单视角/双视角位姿精度和完整任务成功率的证据条件。暂以独立任务成功率点估计>=90%作为高成功率工作目标；最终阈值必须用独立留出布局验证，至少40个独立条件，并报告95% Wilson区间（下界>=80%），同时报告拒绝/失败占总任务比例。该目标是计划，不是已有证据。

本轮固定964347同一开发条件的初态/抬升后/释放前3个快照，每阶段复用已登记32个相机，最多96次渲染测量，不扩大相机搜索。每个满足入画/标定条件的视角用3组固定噪声种子，原3mm噪声/2%缺失不变。每阶段最多24个方向间隔>=10度的双视角组合，按最小目标可见比例的10%区间轮流取样，选择不看拟合精度或真值。视角和噪声重复均不是独立任务样本。

阈值网格10/20/30/40/50/60/70/80/85/90/95%，同一数据回放各阈值。分别统计全14实例门槛和任务目标可见比例；记录像素数、尺寸、连通性，定位比例之外的限制。非比例门槛不修改，几何拟合可在私有诊断中使用低比例/不连通的点云以验证这些门槛的必要性，绝不将这种诊断合格当成正式控制合格。

保留原胶囊先验拟合器，仅输入含噪点云。私有真值独立保存，拟合完成后再计算中心误差和无符号长轴角误差；准确位姿暂定义中心<=10mm且长轴<=12度，沿用现有精度量级，不能等同于能放进箱子。记录质量门槛的误拒绝和误接受；不足128点记失败，不能静默排除。拟合的对称长轴roll不可观测，分割是模拟辅助，尚不是模型语义识别。

快照恢复在独立scene环境，初始化完成后禁用env.step/mj_step/mj_step1/mj_step2，统一mj_forward后生成包围框和点云，避免污染原在线派生缓存。输入文件hash前后不变、完整积分状态逐值不变。训练/模型调用/物理任务动作均0；不重跑6492，不改共享cv_policy或根配置，不Git操作。

实现顺序：阈值和配对纯函数TDD -> 隔离快照渲染/拟合 -> 远端有限运行 -> 独立读取保存点云复算代表性样本 -> 汇总误差/覆盖并更新进度。先探索再选择，当前n=1开发布局，无论技术重复准确率多高，high_success_threshold必须保持null；若数据无法支持候选阈值，如实返回未识别及可执行后续对照。

技能：nature-statistics（单位/选择偏差/证据边界）、test-driven-development、verification-before-completion。串行执行与自审；可用子代理型号不在用户许可列表。
