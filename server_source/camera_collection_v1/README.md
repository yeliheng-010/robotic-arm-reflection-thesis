# 轻遮挡相机采集接线

本目录是新采集版本的首轮工程验证入口，使用已验证的camera_visibility_v6配置；仅有baseline和varied_noisy两种场景。

当前注册pilot为5个既有训练布局的RedBlock→BlueBin任务，最多5次新增执行。旧首轮结果复用作配对参照；不重跑历史条件，不调用语言模型、不训练、不导出SFT。之前9布局中的4个相机拒绝仍在报告分母中。

## 接线

1. `cc_prepare.py`核验旧manifest、审计、相机选择的身份；通过`approved_config`与`adopt`只替换相机，保留布局、配色、噪声、任务和动作参数。旧几何资格不会沿用。
2. `cc_qualify.py`重新渲染验证全部14物体≥85%可见，再执行原投影、噪声点云与碰撞/抓取跨度/关节保护资格。
3. `VisibleSession`在实际执行的首次渲染检查可见性，`GuardedSampler`在每次暂停观测前检查；失败抛出`VisibilityRejected`，不调用公开采集、不生成公开图像。
4. 本轮`cc_worker.py`每布局仅一次尝试，不扩展到恢复分支。不清晰的终态只在`private_audit`留物理审计材料，并明确`public_input_allowed=false`、`training_eligible=false`。
5. `cc_audit.py`独立进程重建初态与终态、逐值核对14实例指标，并复用原传感/轨迹/接触审计。物理成功与后续图像是否可用于模型分别记录。

基线在新包装类中直接调用原实现；本轮不新增基线运行。历史冻结流水线仍未覆盖。扩展多轮恢复采集时须显式使用新Session与Sampler，并保留拒绝状态，不能只换配置后沿用无门禁的Sampler。

## 验证与运行

`test.sbatch`运行7项纯逻辑回归；`smoke.sbatch`真实渲染清晰/遮挡视角并核验拒绝没有产生公开输入；`run.sbatch`依次测试、检查所有入口与源码长度、冻结pilot、运行资格和一次执行/独立审计。

所有结果使用排他创建；已注册或已启动的pilot禁止重复提交。当前实际作业编号和结果见[REPORT.md](REPORT.md)及项目根检查点。未知异常中止，不能补写成失败或通过。

语义识别率不由分割可见率代表。本工程pilot使用已有训练布局与冻结规则执行器，不代表独立泛化、语言模型决策或微调效果评估。
