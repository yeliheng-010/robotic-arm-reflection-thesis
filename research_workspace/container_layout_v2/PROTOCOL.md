# 三容器随机布局资格实验 v2

目标：先检验三个容器位置改变后场景与执行器的可用范围。只研究布局，不声称反思或模型收益。

40个新布局种子950401—950440；两个已有开发任务RedBlock→BlueBin、PurpleCapsule→RedBin；原布局/随机布局，共160条件。三个容器都移动，SortingTray本轮作为场景中的容器参与布局约束，尚未作为任务目标。全为development_qualification，不读最终盲测，不自动训练。

保持物体、朝向、质量、摩擦和反馈不变。关闭挡板和故障注入，一次执行、不修正。各容器XY独立均匀提案，中心范围x=[.85,1.44]m、y=[.15,1.05]m。根据真实编译包围盒检查容器在桌面内、与其他碰撞体及彼此间距至少8mm、每个容器移动至少6cm、至少一对容器在X或Y的相对顺序变化。每种子最多262144次几何拒绝采样，记录拒绝次数；绝不根据物理成功重新选布局。采样分布为这些约束下的条件分布，不代表全桌面均匀采样。

几何通过不等于机械臂可达；可达性/控制执行失败正是本轮需要记录的结果。原布局重复作为配对基线，不将80次原布局任务当作80种不同几何布局；两任务共享40个种子组。原样保留几何拒绝、控制失败、初次成功、无候选和截图，不将失败排除成功率分母。

先CPU冻结与160次编译预检；前2种子共8条件四卡冒烟；审计实际容器坐标、模型零调用、参数、图像hash及物理验收并做4种篡改拒绝；通过后四卡完成其余152条件；最终审计与REPORT.md。工程异常停后继，保存失败现场。几何或物理成功率低本身不构成工程错误，不预设成功率门槛。

每条件独立进程，上限900秒；4个GPU分片、每卡1个worker，无模型服务。单阶段最长6小时，协调总期限8小时。Slurm持久调度不依赖本机开机。禁止无痕重跑；冻结后的修复建立v2。当前仅实现资格任务，后续带噪恢复和微调需依据结果另立协议。
