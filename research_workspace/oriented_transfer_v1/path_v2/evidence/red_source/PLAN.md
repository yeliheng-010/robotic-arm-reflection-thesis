# 持物路径支撑接触与模块化修订

6454在抬升第二采样点被源胶囊与simple_table的残余支撑接触拦截（约0.192mm）。该规则把尚未完全脱离支撑面的初始接触与新增碰撞混同。旧版本/账本保持。

新增Guard仅允许原已存在的源物体-支持面几何对，在姿态不变、XY不变、Z单调上升的lift段中穿入深度逐样本不增加（1nm数值界）。不得新增几何对，脱离后不得再接触，任何其他阶段不允许此例外。真实固定输入回归必须确认原支撑接触实际逐步减少；若不减少照常拒绝。

其他路径候选、51点采样、256边/256前缀/512运输、限位、自碰撞、箱体净空和时长限制均不改。提取较复杂的单样本检查与前缀检查为独立函数；新版本结果与旧版的不同应仅来自上述严格支撑退出语义。
