# 有限倾斜放置端点验证

触发证据：6447同抓取分支的8个绕世界竖轴朝向、4096端点均碰撞；6448固定首抓点/中心最低高度的8朝向×8IK分支均碰撞，涉及upper_arm_link/forearm_link与RedBin。原数据、布局、安全阈值和分母不变。

本阶段只读验证TCP倾斜是否能改变机械臂接近目标箱的姿态。按原优先序保留前2个不同的已验证抓取姿态，不根据私有碰撞原因逐例挑选；释放时绕世界z轴0/±45/±90/±135/180度，再绕夹爪局部y（闭合轴）0/±15/±30度。释放逆运动学8分支独立枚举；不假设能从抓取分支连续到达。

每条件最多2048端点检查，沿用原网格和.01/.04/.07m底部间隙，先中心再其他网格。使用SE(3)变换后的保守几何体积与原20mm箱内余量、10mm机械臂净空、限位、自碰撞及真实持物碰撞检查。先RED/GREEN，再静态探针与独立进程逐行复算。每进程600秒、无物理/模型/训练。

若有合格端点，才允许进入前缀和持物完整链验证；若仍拒绝，停止继续扩大本轮姿态族，保留有限预算拒绝而非全局无解结论。
