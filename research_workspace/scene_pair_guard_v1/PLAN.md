# 接触例外和释放门控修复

目标：拒绝机械臂/夹爪碰目标箱；源物体只豁免指垫；松爪前核对实际到位与持物。
范围：独立进程内适配，不修改冻结引擎/schema/错误枚举；保留baseline/varied_noisy、布局、相机、3mm/2%噪声及旧结果。不训练、不推广。
接触：机器人内部接触和原支撑面规则不变；被搬物体与目标箱的合法接触不改变。静态路径与动态监控使用同一新增规则。
释放：必须有双侧目标接触；实际TCP相对命令释放点XY误差≤20mm、Z误差≤40mm。阈值是本轮事前工程容差，不能声称来自独立数据标定。未满足时中止，不开夹爪；不追加观测或仿真等待。
风险：新增保护可能误拒绝旧成功；先离线影子检查，再覆盖所有5个增强成功、baseline两任务和两个已证实漏检失败，固定首个尝试。必要时单独回放release-only失败分支以检验不受更早碰撞中止遮蔽的门控。

- [x] 新动态/静态接触适配和释放包装器；测试拒绝时原松爪函数不被调用。
- [x] 冻结协议，扫描6份诊断轨迹的影子判定。
- [x] Slurm定向物理回归；记录停止时间、真实接触/门控证据，不把提前失败当成功。
- [x] 独立审计、报告、项目交接。v1出现1个旧成功退步，未推广；v2收窄范围并验证，见其报告。
