# 当前场景：仅两种配置

当前使用入口为 `pair_run.py`，只接受以下两种配置：

| 配置 | 行为 |
|---|---|
| `baseline` 原配置 | 原始布局、物体朝向、箱体颜色和相机，无新增传感器噪声 |
| `varied_noisy` 全部变化＋噪声 | 物体与容器全局布局、物体朝向、容器六色配色、相机位置/朝向/视场角同时变化；深度高斯噪声标准差3 mm、截断±9 mm，2%有效深度像素缺失 |

两者使用相同执行器和成功判据。增强配置保留桌面边界、物体间距与编译几何检查；可见性不足单独记录为资格拒绝，不重抽种子。

## 使用

在 Slurm 分配的环境中，先加载本目录的 `environment.sh`，然后选择其一：

```bash
$SIM_PY pair_run.py --scene baseline --seed 960102 --output runs/original_960102
$SIM_PY pair_run.py --scene varied_noisy --seed 960102 --output runs/varied_noisy_960102
```

输出目录必须尚不存在，禁止覆盖已有执行证据。默认任务为 RedBlock → BlueBin；也支持 PurpleCapsule → RedBin，以 `--source` 和 `--destination` 指定。

当前复用已经登记并检查过的开发种子960101–960112。种子控制具体场景，不构成额外档位；两个配置均不暴露单因素开关或噪声强度选择。

## 范围与证据

噪声进入真实渲染深度，进而影响点云和抓取；RGB不叠加装饰性噪点。每次尝试保留干净/受扰深度、传感器统计和实际执行记录。场景固定，噪声流随外层尝试编号变化，重跑同编号可复现。

“全部变化”指当前已实现的全局布局、物体朝向、箱体配色和相机变化。容器自身旋转、质量/摩擦与光照尚未扩展。定位/分割仍由仿真真值辅助，物理验收保持无噪真值；不能将结果解释为纯视觉颜色理解或实机泛化。

旧 `scene_diversity_v2` 只作为冻结实现依赖和历史证据，旧分组不再作为当前可选场景。新验证只针对上表两种配置，不重跑旧六组实验，不调用模型或训练。
