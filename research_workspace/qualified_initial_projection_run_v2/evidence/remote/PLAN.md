# v2单次双侧几何构造与独立审计

用户采纳已验证v2的一次求解建议。本目录独立于v2实现和v1失败；仅授权每侧一次SLSQP、一次独立审计。初始化、动力学积分、模型生成及训练预算全部0；不修改旧规则文件的execution_authorized=false历史截点。

1. 绑定v2源码清单、6873验证结果、原after状态及NEXT_RUN_RULES副本。定向测试一次性记录、预算及状态掩码；来源核验通过后在本目录登记新的几何授权。
2. 调用冻结v2适配器，每侧一次，从原参考角的裁剪值开始。每侧调用前独占写claim，调用后保存终止状态和主要迭代点；无重启、补搜、热启动或放宽容差。
3. 仅当两侧均accepted且optimizer_success，完整3维XML连接、原8关节限位、0.01rad上限、driver等式及其余状态精确保持均通过，才写新candidate_state.npz。原状态不改；任一侧失败则整候选拒绝。
4. 独立进程创建最多1个无接触/驱动的隔离MuJoCo模型，仅使用mj_kinematics。核对编译模型限位/等式与原参数；原source与reference精确一致，允许掩码外全部积分状态精确一致；独立复算连接和driver，核对候选角与两侧求解结果。完整3维世界残差≤1e-7m，driver≤1e-7rad，公式与运动学对照atol=1e-12m。
5. 构造拒绝时审计只核查拒绝证据，不生成候选。异常时保留逐侧claim/结果及failure.json，进行失败证据审计，不重试。
6. 保存作业状态、来源、输出、独立审计并归档；完整场景禁碰、attach、视觉资格、动态稳定性仍未覆盖，几何通过不能解除生产安全拒绝。

执行前测试不调用真实优化器或构造模型；只验证新增一次性入口与状态约束。旧12项v2测试及旧求解不重复。采用定向验证、串行自审与verification-before-completion，全部测试/数值计算走Slurm。
