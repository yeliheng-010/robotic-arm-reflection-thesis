# 通用等价关节角入口

推荐入口为 `jv_entry.Session`。先在 Slurm 作业中 source 本目录 `environment.sh`，再由新、独立登记的任务运行器使用该 Session；不要覆盖旧冻结运行器或重跑已消费条件。涉及真实渲染的作业必须申请 GPU。

## 行为边界

- `baseline` 和 `strategy != observed_top` 委托原 `cc_runtime.VisibleSession`。
- `varied_noisy + observed_top` 使用通用规划。原顶面方案完整通过时直接返回；只有失败才尝试扩展抓点及合法等价关节角。
- 备用关节角由当前关节状态和真实限位生成，不读取条件编号或失败标签。每条件共享最多256次预抓取边检查；沿用原51点碰撞检查、限位、夹爪跨度与净空保护。
- 备用预抓取段按最大速度1 rad/s、加速度2 rad/s²计算时长。端点和时长随选中候选保存，静态检查和执行读取同一数据。
- 多阶段候选分别保存审计账本，保持阶段内候选一致性断言；`candidate_stages` 保存阶段历史。
- 使用进程内临时 patch，仿真会话应独立进程运行，不支持多个线程同时执行不同会话。

## 已验证范围

6433：9个固定快照在独立进程中复算一致；7个完整计划通过、2个胶囊拒绝。六个原方案不变，另一方块自动选出6429已物理验证的等价角方案。

6436：两个真实 GPU 感知入口的四组观测数组、完整计划分别与旧输入及静态审计逐值一致；在任何任务动作前强制停止。6439：对外入口分派3项测试通过。两类证据互补，不能描述为对外入口的全场景物理测试。

完整物理成功仍引用原6429及其他历史成功轨迹；本轮新增物理尝试0。尚未将此入口接到所有冻结采集、模型对照及训练流水线。

## 后续物理审计接入

新任务须登记独立输出路径与未消费预算，先做真实 GPU 输入/计划匹配。几何审计使用 `jg_paths.context()`，按 `joint_option` 重建预抓取端点和时长。若最后候选阶段使用扩展生成器，审计也必须使用该生成器并复算所有阶段；不能沿用只重建原两个顶面候选的旧审计入口。

`observed_yaw_v1` 和 `observed_long_v1` 仍是独立胶囊探针，未接入此默认入口，两条件都未找到完整安全计划。
