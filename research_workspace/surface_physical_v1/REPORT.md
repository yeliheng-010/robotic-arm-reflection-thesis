## 失败证据与解释边界

| 观测/审计量 | 结果 |
|---|---:|
| 搬运阶段采样 | 227条 |
| 记录到双侧指垫接触胶囊的搬运采样 | 227/227 |
| 搬运前后物体中心在夹爪坐标系中的位移 | 64.96mm |
| 释放前物体中心相对静态预测的三维偏差 | 63.33mm |
| 原释放保护检查的夹爪水平目标误差 | 2.75mm |
| 终态物体中心相对箱中心的水平偏差 | 81.34mm |
| 原终态判据 | inside_xy=false；inside_z/supported/settled=true |

胶囊确实被抓起并搬运到目标附近，故不能将本例简单归类成“没有抓住”或“搬运时完全脱离夹爪”。离散采样中的双侧接触并不保证物体相对夹爪的位姿固定。记录确认约65mm相对位置变化，但仅凭这些数据不能唯一分解滚动、滑移、接触重排或弹性跟踪各自贡献。

当前释放门槛检查夹爪TCP到目标、以及夹持接触；它没有验证实际物体姿态仍符合规划时的刚性附着假设。TCP到位而物体落点不合格的差异，支持下一阶段优先验证持物姿态估计与放置闭环。不能把“静态持物碰撞检查通过”当作“稳定夹持或正确入箱”的证明。

以上位姿量来自私有仿真真值和接触审计，**不得直接作为模型输入或人为预填的掉落原因**。未来模型应从允许的视觉/深度、机器人状态和标准反馈自行判断；仿真真值只用于独立评价其判断与控制效果。
