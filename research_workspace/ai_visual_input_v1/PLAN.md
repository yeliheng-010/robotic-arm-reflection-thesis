# 图像与执行事实输入接线

已有自然闭环的Qwen3.5-4B只接收文本深度/遥测摘要，RGB虽保存但未入模。现用已审计的V0_962501_varied_noisy首次失败现场验证多模态接口，不新增环境尝试，不继续耗尽轨迹，不作训练。

同一基础模型、adapter关闭、seed42、确定性生成、最大2048输出token。direct/diagnostic各一次请求，共2次；共享同一第0帧RGB、确定性源物体邻域裁剪和同一公开输入。裁剪仅从当时保存的分割mask确定ROI，使用原始RGB，不画标签或提示正确原因；明确仍有仿真分割辅助。

公开输入加入任务完成布尔信号、规划是否获准、动作是否开始、计划/实际时长，不加入错误类别、接触根因、物体真值或未来结果。动作沿用已接线STOP/OBSERVE/RETRY/SET_TIME_SCALE/SET_GRASP_OFFSET，此处只验证提议和图像接线，不执行新动作，不声称诊断正确。

CPU准备：核对来源审计身份，重建共同请求，生成并冻结图像/裁剪及输入身份。GPU只做2次生成并保存图像网格、像素张量形状、输入长度与结束原因。图像处理最大448×448像素量级，保留原始长宽比。调用失败记录，不网络重试或自动替换输出。
