# 真实后果监督采集执行计划

使用 writing-plans 与 executing-plans，在本会话串行实现并核验。

目标：只保留 baseline 与 varied_noisy 场景，在新种子上形成有实际后继执行支持的动作监督。不得把模型解释、几何规划成功、重复观测当作恢复。

- [ ] 冻结协议和种子隔离，复用已验证的观测/有限路径资格，保留全部拒绝。
- [ ] 实现三条预登记探索分支、公开输入、逐尝试独立重建审计。
- [ ] 运行首批 24 训练种子、8 开发种子的资格与物理采集，检查动作覆盖和收益。
- [ ] 通过首批审查后按批扩充；不混入已有 pilot。每批最多 64 增强条件和 2 原配置控制，最多 462 物理执行、0 模型调用。
- [ ] 导出动作 SFT 候选、负结果账本及独立开发集；运行来源、种子、去重、动作一致性和泄漏检查。
- [ ] 达到原门槛后冻结训练包和基础模型对照，进入受控试训阶段。

分支在首次自然失败前固定：top_then_slow、lower_then_slow、slow_then_top。每分支共享首次执行，最多再执行两次；每条件最多 7 次实际执行。下移为世界 Z -30mm，减速为时间倍率 3，顶面策略沿用已验证的 observed_top。所有分支使用同一 0.20m 抬升、安全路径、自碰撞、限位、10mm 箱净空，全部从原始含噪观测生成动作几何。探索分支不能作为等预算 AI 性能比较。

模型输入由现有真实 before/latest RGB 与公开观测接口产生；成功后 STOP 单列，失败动作保留为负结果，不写成 SFT 正确动作。只对紧邻的真实成功后继写“此轨迹已验证恢复”，不标唯一最优，不生成正确根因。OBSERVE 不在预登记探索序列中，不能由本数据声称已学会主动观察。

训练快照≥120/24种子组、开发≥40/8组、训练恢复≥40/12组、≥2种有效修正、覆盖两任务、隐藏字段隔离及基础模型学习缺口门槛保持。仅数量达标仍不能声称泛化充分。资格筛选后的条件成功率与原分布覆盖率同时报告。

风险：资格和自然失败率可能较低；顶面策略可能成为唯一有效动作。首批和后续每批都按有效快照/恢复/动作类型审查，若持续无新增有效信息，停止盲目扩量并修订后续未冻结协议。冻结源、已消费轨迹和最终盲测保持隔离。

文件边界：rc_protocol/rc_qualification 负责预约和资格；collect_worker/rc_branch 负责真实探索；rc_audit 负责独立重建；rc_review/rc_gate 负责去重、导出和训练门禁。全部新文件，不覆盖旧冻结实现。仿真和模型只走 Slurm。
