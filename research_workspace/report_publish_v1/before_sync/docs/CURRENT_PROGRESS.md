## 研究边界与近期顺序

当前结果均来自 MuJoCo、结构化文本反馈与合成传感器噪声。历史模型实验仍有理想错误标签；新接线版本已从策略输入隔离这些标签，并在工程中止状态实测连续RGB-D观测及新噪声，从带噪深度生成表面摘要；分割仍使用仿真辅助。工程中止不代表自然掉落，没有实物相机、真机迁移或最终盲测结论。相关种子组数较少，不宣称统计显著性或广泛泛化。

下一步按顺序推进：在预登记自然失败条件核对证据支持度 → 比较同预算固定规则、AI直接决策和AI诊断决策的实际补看/修正后果 → 冻结策略后独立评估。两AI共享补看权限和预算，避免混淆诊断输出与额外观测的效果；不把缺乏支持的模型假设直接作监督标签。具体见[路线图](ROADMAP.md)、[自主诊断协议](../../ai_diagnosis_v1/PROTOCOL.md)及[最新模型冒烟报告](../../ai_diagnosis_failure_v1/REPORT.md)。
