# 两场景执行器：增加抬升掉落补救

当前仍只有两种场景：`baseline`原配置；`varied_noisy`全部变化＋噪声。

增强场景保持物体/容器全局布局、物体朝向、箱体配色、相机位置/朝向/FOV变化，以及3 mm深度噪声、2%深度缺失。没有降低扰动强度。

## 修复内容

仅当上一轮在抬升阶段掉落、XY偏差不超过2 mm，且已到第三次尝试时，优先评估世界竖直抓取。候选仍通过原完整路径检查和动态接触监控；原姿态保留为回退。前两次执行和其他失败处理不变，两个场景使用相同策略。

旧960102增强场景原来三次均掉落，现在第三次world_down_0成功；与旧记录比对前两次候选、噪声、参数、路径及物理结果完全一致。原配置仍首次成功。详见`DIAGNOSIS.json`、`anchor_verification.json`和`anchor/varied_noisy/attempt_3/result.json`。

## 使用

在Slurm环境中加载本目录`environment.sh`：

```bash
$SIM_PY pair_run.py --scene baseline --seed 960102 --output runs/original_960102
$SIM_PY pair_run.py --scene varied_noisy --seed 960102 --output runs/varied_noisy_960102
```

支持已登记种子960101–960112。输出目录必须不存在。默认任务RedBlock→BlueBin，也支持通过`--source`、`--destination`选择PurpleCapsule→RedBin。不会启动训练或语言模型调用。
