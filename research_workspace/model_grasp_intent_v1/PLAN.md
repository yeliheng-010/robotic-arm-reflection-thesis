# 模型抓取意图闭环：本地接线阶段

目标：允许模型基于合格的公开观测选择抓取区域、深度、接近方向，在规划拒绝后重新决策；底层继续承担几何、IK、路径和安全检查。

本轮用户已接受方案。采用独立版本，不修改冻结动作接口，不覆盖旧实验、权重、来源记录。仅 baseline / varied_noisy，当前仍 7 随机实例 / 7 固定背景。初态视角不合格条件不进入本轮。

## 顺序与验收

1. 核对现有请求、模型客户端、候选生成和安全规划接线。
2. 新增有界抓取意图契约、可观测几何投影、明确坐标约定。
3. 新增模型提议—规划检查—有限反馈—再次提议的无运动控制器；与规则策略共用请求、动作和预算。
4. 用真实函数的本地测试验证参数边界、空间转换、隐私隔离、预算消耗、拒绝后调整、无运动限制和旧源码不变。
5. 更新进度与证据，区分本地接线、真实模型、GPU规划和物理成功。

## 边界

- 本地规划回调的测试不冒充 MuJoCo 安全验证或模型推理。
- 本轮无真实执行入口，不提交 Slurm、不调用模型、不训练、不操作 Git 远端。
- 不改变 50mm 抓点位移上限；新方向仅生成提案，不意味着夹持稳定或可达。
- 只从许可观测构造模型输入。私有碰撞对、仿真尺寸、物体真值、人工原因不得进入请求。
- 规划拒绝反馈只报告标准化状态，不拼接异常文本或原始规划日志。
- 规划尝试、决策和追加观测分开计数；预算消耗后不得因拒绝或异常重置。
- 现有 sv_client / service 与历史 manifest 绑定，新契约不能直接假借旧入口请求模型；后续需独立登记真实服务接线和实验预算。

## 后续实验门槛

先通过独立完整路径审计和 GPU 零运动入口核验，再登记有限物理尝试。先以 964347 胶囊为开发案例，随后使用未消费的新条件对比规则 / base / adapter；同观测、动作空间、预算和安全门槛。不能用当前 3/8 累计工程证据宣称模型收益。
