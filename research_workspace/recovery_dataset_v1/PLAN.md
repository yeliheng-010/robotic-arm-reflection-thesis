# 按真实后果导出动作监督

只读取 recovery_collection_v1 的已完整审计批次；不把旧 pilot 或待完成条件纳入正式训练。每个模型输入仅由既有公开请求和两幅真实 RGB 构造，目标只含已执行成功的 action。原因猜测、未来后果与私有资格字段留在审计账本。

共享现场以 task/state/clean 去重；同一实际输入的多个成功动作保留为 accepted_actions，SFT 目标按稳定 JSON 排序选一个，不宣称唯一最优。失败动作保存在 outcomes，不能输出为正 SFT 目标。成功后的 STOP 另外导出并限制在正恢复数的 1/2 以下，避免 STOP 样本淹没修正动作。全部成功原始例仍保留在 inventory。

训练、开发严格按整个布局种子组隔离。数量门槛和导出验证、基础模型对照、受控训练协议分开；没有完成后两项，training_ready 必须为 false。数据不足时仍输出明确缺口，不启动训练。
