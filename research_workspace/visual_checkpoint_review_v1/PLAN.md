# 正式多模态训练产物重载审查

目标：正式训练完成后，在新的 Slurm GPU 进程加载最终 adapter，验证保存前后的参考 logits 一致。只读训练结果，不进行生成、优化器更新或仿真，不以重载成功代表性能提升。

边界：新增独立目录；现有冻结采集、训练代码及数据门槛不变。先验证本目录的拒绝路径、完整样本覆盖及真实入口解析；正式执行必须等待训练成功，不重复已消费训练。

验收：训练数据身份一致；更新序列覆盖每个训练样本且恰好一次；记录有限损失和正梯度、参数确有变化；最终 adapter/参考 logits 哈希有效；独立重载输出形状一致、全部有限且最大绝对误差不超过 1e-4。保存源文件、训练清单和结果身份。

本审查只验证最终产物可重载。尚需独立开发动作评价及新布局物理闭环，才能判断模型效果。
